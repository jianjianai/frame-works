# 复盘：《unhappy》（57 秒，2026-10-07 23 点发布，数据到 10-10 23 点，约 72 小时）
同一段聊天两个视角：他以为她只回「嗯」是不喜欢他，其实她每个「嗯」后面都删掉了一整段话。原始数据：创作者中心导出的 6 个 xlsx，在 raw/2026-10-10/（没有导出全部评论），已导入。

剧情和歌：主歌1（0–16.4）他的视角：钩子聊天（他一大段、「对方正在输入」闪两次、她回「嗯」）→ 他的脸 → 往上翻到 7 月的长消息 → 她的朋友圈「今天好开心～」→ 回忆：上课她躲到书后、递草莓牛奶她拉着朋友跑掉 → 打了又删，只发「以后不打扰你了」→ 关灯。副歌1（16.4–32.8）：翻她的相册 → 黑屏里他的倒影 → 流泪、镜头穿过眼睛盯着「嗯」→ 关机 → 蒙进被子 → 一镜退出他的窗、灯灭、甩到她的窗 → 28.1 反转：她也在哭 → 29.7 她输入框里打好的整段话，按住「发送」没松 → 回主页。主歌2（32.8–49.1）她的视角：小美教她「回个嗯就行」→ 全删只发「嗯」→ 上课她在书后脸红 → 拿走他的草莓牛奶 → 39.4 回到现在，把那段话改完发出去 → 没有回音 → 第二天他开机，看到「其实，我喜欢你」。尾奏（49.1–57，没有人声）：他笑 →「我也是」→ 约周末去图书馆 →「嗯！！」→ 早晨的街 + 点赞和评论引导。用到的 17 句歌词没有重复。首帧钩子「我发了一大段 / 她只回了一个「嗯」」。

## 结论
- 题材能传：分享率 2.81%、消息页来源 3.2%（平均约 1.8%），留存是四支里最差的，72 小时还是有 24.08 万播放。「只回一个嗯」是观众会转给某个人看的题材。
- 留存输在前半段的结构：前 28 秒是同一个结论的更多证据加 12 秒难过，反转时只剩 15.2%（同类 28.7%）。57 秒、反转 28 秒都做到了，和重置版一样：缩短、提前不够。
- 反转用一段要读的长文字讲出来，按下发送那一秒是四支里最大的漏点；答案揭晓后要马上有下一个问题。
- 兑现后的尾奏又掉一截：第四次验证「歌声停了还在放的画面会掉人」。
