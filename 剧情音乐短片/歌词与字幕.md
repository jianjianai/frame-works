# 歌词与字幕
中英双语卡拉 OK 歌词的时间、对齐、翻译、排版和字体。

## 逐词时间
- 做法：用酷狗 KRC 拿英文逐字时间：`krcs.kugou.com/search?ver=1&man=yes&client=mobi&keyword=歌手 - 歌名&duration=毫秒` 得到 id 和 accesskey → `lyrics.kugou.com/download?ver=1&client=pc&fmt=krc&charset=utf8&id=…&accesskey=…` 的 content 做 base64 解码、去掉前 4 字节、按密钥 [64,71,97,119,94,50,116,71,81,54,49,45,206,210,110,105] 循环异或、zlib 解压。先核对 KRC 时长和音频一致。
- 避免：凭听感或响度猜时间。

## 中文和英文按节奏一一对应
- 什么时候用：双语卡拉 OK 歌词
- 做法：英文每唱出一个单词，中文就亮一个词。每句中文写成数组，词数等于英文单词数，第 i 个中文词用第 i 个英文单词的时间；对应的是出现的节奏，不要求每个词意思对上。词数不一致直接报错。
- 翻译：整句中文字数尽量等于英文音节数（一个汉字一个音节），看中文也能跟上旋律；音节和意思冲突时，优先意思、情绪准确和句子通顺，多一两个字可以接受。
- 例：Today / I / realized / that / I / have / no / friends / and / I'm / so / alone（16 音节）→ 今天 / 我 / 发现 / 了 / 我 / 没 / 有 / 朋友 / 而 / 我 / 好 / 孤单（16 字）
- 避免：逐字平均分时间；整句一起亮；为了让每个词意思对上把句子写长（字数远多于音节，跟不上旋律）。

## 排版（1080×1920）
- 英文 58px、宽 ≤820；中文 64px，超过 900px 宽时在两半最均衡的空格处折行，词间空格占半个字。歌词块中心 y≈1335，顶部 y<180、右侧按钮区留空。
- 正在唱的词放大 ≤6%，整块不随节拍动。
- 字幕不用播放器的 subtitles，直接画在 scene 图层里。

## 字体
- 中文网络字体用 Google Fonts `css2?family=…&text=<全部用到的字>` 取子集 woff2（几十 KB），改字后重新生成。加载先 fetch 成 ArrayBuffer 再 `new FontFace`，失败再用 `url("…")`。
