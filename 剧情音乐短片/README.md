# 剧情音乐短片

抖音剧情 MV 发布后的复盘经验：数据、结论和下一支要怎么改。目前有两支作品的数据：work-bdd5c2f8《i have no friends》（99 秒，首日 25 小时）、work-9586fbc4《mirrors》瑕疵：0（57.5 秒，发布后约 40 小时）。结论在新作品上继续验证、补充。

## 文档
- 下次怎么做.md：从复盘得出的做法，按结构、开场、结尾、反转、文案、发布整理。开工前先看。
- 复盘数据.md：每支视频的完整数据（播放、互动、流量曲线、逐秒流失、评论）、各作品对比表，以及复盘的方法。
- 画面风格、歌词排版、代码等制作经验在经验库「s0rrow」。

## 一句话结论
- 《i have no friends》：互动强（点赞率 7.11%）、留存弱（完播 4.16%、平均看 15 秒）：重复已知信息的情绪蒙太奇在大量掉人，反转在 67 秒时只剩 5.7% 的人看到。
- 《mirrors》按上面的结论做（57.5 秒、开场 5 秒四镜、反转 32.5 秒、每个镜头推进剧情）：首 24 小时 35.97 万播放（上一支 5.55 万），2s 跳出 18.75%、5s 留存 62.53%、反转时还有 33.6%，前 32 秒每一段都比同类少掉人。漏点在结尾：兑现后又放了 12 秒，47–54 秒掉人是同类的 1.5–2.3 倍；评论率只有 0.09%。
- 下一支：45–60 秒、开场多镜头、反转 30 秒前后、每个镜头推进剧情；兑现后 3–5 秒内结束；评论问题写进标题或置顶评论。
