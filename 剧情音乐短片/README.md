# 剧情音乐短片

抖音竖屏剧情 MV（歌曲 + 手绘剧情 + 中英歌词）的制作经验；带数字的结论来自已发布作品的数据复盘。

## 用户偏好

- 目标是抖音爆款：开头抓人、有看完能回味的剧情/反转、中英双语歌词。
- 中文歌词要大（1080 宽约 64px）；英文唱出一个词，中文就亮一个词（按出现的节奏对应，不要求逐词意思对应）。翻译时中文字数尽量等于英文音节数，方便跟旋律，但意思、情绪准确和句子通顺优先（见 歌词与字幕.md）。
- 歌词不要随节拍弹跳，只让正在唱的词轻微放大。
- 用户说画面「奇怪」，多半是结构问题（姿势不合常理、肢体像拼起来的、遮挡像戴面具）：先看全尺寸截图找原因，重画结构，不要只调参数。
- 时间写法常是「秒:百分秒」：「7:79」= 0:07.79，「39:07」= 0:39.07。
- 发布后会上传创作者中心导出的 xlsx 要求复盘（见 发布与复盘.md）。

## 通用做法

- 每个镜头都要推进剧情：剧情推进时留存和同类持平，重复已知信息的情绪蒙太奇（再唱一遍同样的副歌、空镜）流失是同类的 2–3 倍（见 留存与节奏.md）。
- 时长 45–60 秒，反转/高潮放在 30 秒前后，兑现后马上收尾；不要为了用整首歌保留重复的副歌。
- 第一人称的处境文字（「今天是我17岁生日」）会被观众当成作者本人的经历，评论大多是对作者说的；评论多不代表剧情被看懂（见 发布与复盘.md）。
- 反转要让人看懂「为什么」：伏笔可以藏，动机必须拍出来。
