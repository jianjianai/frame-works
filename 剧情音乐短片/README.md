# 剧情音乐短片

抖音剧情 MV 发布后的复盘经验：数据、结论和下一支要怎么改。目前只有一支作品的数据（work-bdd5c2f8《i have no friends》，99 秒，首日 25 小时），结论要在下一支上验证、补充。

## 文档
- 下次怎么做.md：从复盘得出的做法，按结构、开场、结尾、反转、文案、发布整理。开工前先看。
- 复盘数据.md：这支视频的完整数据（播放、互动、流量曲线、逐秒流失、评论），以及复盘的方法。

## 一句话结论
互动强（点赞率 7.11%）、留存弱（完播 4.16%、平均看 15 秒）：重复已知信息的情绪蒙太奇在大量掉人，反转在 67 秒时只剩 5.7% 的人看到。下一支做 45–60 秒、反转放 30 秒前后、每个镜头都推进剧情。
