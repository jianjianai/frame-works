# 复盘数据
各作品发布后的数据记录和复盘方法；新作品发布后在这里追加一节，和已有数据对比。

## 复盘方法
- 数据：创作者中心导出的 xlsx（流量每小时播放、内容吸引力逐秒留存 + 同类作品、观众参与度、观众、粉丝、全部评论）。环境里没有 python 和 unzip：用 node 加载 `node_modules/.pnpm/fflate@*/node_modules/fflate` 解压，再用正则读 sharedStrings 和 sheet XML。
- 逐秒流失率 = 这一秒走掉的人 ÷ 当时还在的人；除以同类作品同一秒的流失率得到倍数。把镜头按内容归类（剧情推进 / 情绪蒙太奇 / 尾声）算平均倍数，看哪类内容在掉人。
- 把流失归到某个画面前，先比较它之前、当时、之后各 2–3 秒的倍数，只有当时或之后 1–2 秒明显升高才算。曾把流失误判为黑场造成，实际是紧接着重新唱起的副歌。
- 评论按主题计数，分开「对作者说的」和「对剧情说的」。
