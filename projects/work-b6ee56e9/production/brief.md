# 创作设计

命题：一张纸如何从被规定的形状，走向自己的方向。

画面母题只用红纸和 64 个建筑构件，不以文字卡片或不同无关素材拼接。开场近距离建立纸面；由折痕生出规则，规则形成无尽长廊，空间收紧。60 秒声画同时屏息，63.75 秒重拍释放：机械门框成为自由波动的平面。纸带经历大尺度曲面变形后重新成为纸张，折成飞机。最后，不仅红纸离开，原来的 64 个构件也折成纸飞机一起起飞。

色彩从暖灰与深红进入冷黑与钢蓝，再返回温暖的纸色。相机优先保证主体可读，允许局部遮挡作为连续擦镜，但不长时间隔着柱体展示关键动作。主段镜头顺势加速和减速，屏息段真正停止。

音乐为原创 128 BPM 多轨电子乐，不使用旋律采样或外部背景音乐。早段以短促脉冲与低频强调秩序；中段加密；屏息后进入主题旋律，最后以展开的和弦和钟音结束。纸面动作有独立拟音，声音并非无差别贯穿全片。

字幕是可关闭的补充，不承担说明每一动作的任务。无对白旁白。末句：把折痕，折成翅膀。

工程说明与入口见 ../README.md；过程记录单独保存在 ../records/。
