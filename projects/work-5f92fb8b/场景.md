# 《默 默》场景

都是空场景，16:9，提示词直接复制去生成图片。只出现一次的地方（酒店前台、深夜街道和药店、医院门口药房、酒店门口、闪回雨夜）不用做，交给模型。

高铁站出站口（深夜），用在第 1 组：
```
写实电影场景照，35mm 胶片质感，16:9。疫情防控时期的中国高铁站出站口，冬天深夜，高处的玻璃窗外一片漆黑。一排一人高的铁栅栏横在画面中间，把出口拦住。镜头在旅客等候区这一侧；隔着栅栏，对面是空荡荡的出口通道，有白色防疫帐篷、测温门和蓝白隔离带。惨白的顶灯。空场景，没有人，没有可读的文字。
```
