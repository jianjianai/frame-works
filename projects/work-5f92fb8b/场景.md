# 《默 默》场景

都是空场景，16:9，提示词直接复制去生成图片。只出现在一组里的地方不用做场景图，交给模型，站位在提示词里写清楚：高铁站出站口（第 1 组）、高铁车厢（第 2 组）、酒店前台和深夜街道（第 8 组）、药店、医院门口药房和酒店门口（第 9 组）、闪回雨夜（第 6 组）。

病房（深夜），用在第 5、10 组：
```
写实电影场景照，35mm 胶片质感，16:9。中国普通医院的双人病房，深夜。两张病床并排，中间是床头柜和墙上的呼叫铃；靠窗那张床上方装着骨科牵引架，靠门那张床边立着心电监护仪。镜头在床尾，两张床都看得见。只亮着一盏床头小灯，暖黄的光落在两张床之间。现实题材电影，不是恐怖片。空场景，没有人，没有可读的文字。
```

病房（白天），用在第 3、13 组。把“病房（深夜）”那张图当参考上传：
```
同一个房间，同样的机位，改成白天，阳光从窗户照进来，明亮温暖。空场景，没有人，没有可读的文字。
```

酒店走廊（九楼，深夜），用在第 4、7、11 组：
```
写实电影场景照，35mm 胶片质感，16:9。中国普通商务酒店的客房走廊，深夜。地毯，米色墙，两扇客房门面对面，走廊尽头是电梯。镜头在走廊中间朝电梯看，两扇门在画面左右两边。暖白色的顶灯。现实题材电影，不是恐怖片。空场景，没有人，门上没有门牌和封条，没有可读的文字。
```

陈默的房间，用在第 4、12 组：
```
写实电影场景照，35mm 胶片质感，16:9。中国普通商务酒店的单人间，深夜。一张单人床，床边一扇窗，窗外是城市夜景，远处有一栋亮着灯的医院大楼。房门上有猫眼，门下的缝里透进走廊的光。暖黄的床头灯。空场景，没有人，没有可读的文字。
```

场景图的机位要放在主要人物站的那一边：模型会把人放进场景图前景的空地上。
