# 《默 默》分段提示词（Seedance 2.5）

全片共 19 组，**组号就是剪辑顺序**，剪辑时按 1→19 连着剪，不用从任何一组中间切开。只有前后相邻、同一个地方、时间连着的戏才合在一组生成（不相邻的戏不合，哪怕在同一个地方），每组最长 30 秒，时长写在每组标题里，生成时在 Seedance 里设置，不写进提示词。每次生成：复制【全局提示词】，接上一组（从 @ 行开始复制，前情提要、场景布局和故事都要）。闪回那组自带背景，不贴全局提示词。参考图见 `角色.md`、`场景.md`、`物品.md`，写法见 `用法.md`。

## 全局提示词

```
写实真人电影，中国现实题材，胶片质感，色调克制。2022 年冬天，疫情防控时期的一座中国普通城市：公共场所的人都戴口罩，防疫工作人员穿白色防护服；人们疲惫、焦虑，但彼此之间有克制的善意。不要字幕，画面里没有可读的文字，不要背景音乐。人物的长相和穿着完全按参考图；场景图只参考布局和陈设，时间和光线按下面写的；音频只参考说话人的音色。台词用标准普通话，吐字清楚，逐字照说，不加词、不改词，每句只由标明的人说；没写台词的人不说话；画外音响起时，画面里的人不张嘴；戴着口罩说话的人和画外音也一样清楚。每组里「前情提要」后面的文字，只是让你了解人物此刻的处境和情绪，不要拍成画面，不要念出来，也不要出字幕；只拍「故事」里写的内容。每组的「场景布局」写的是这个地方的东西都在哪、哪边是哪边，所有人和东西都按它摆放，人往哪走也按它来，不要自己改动位置；场景布局本身不用单独拍。
人物：陈默；陈默的父亲；老周是父亲隔壁床的病友；朵朵和朵朵妈妈是母女。陈默和朵朵母女、老周都互不相识。
```

## 分组

医院和酒店两条线来回切，切的地方都在组与组之间，一组内部时间地点都是连着的。

### 第 8 组 闪回·雨夜（8 秒）

（这一组不贴全局提示词，第一行是它自己的全局提示词，写的是 1999 年。这一组没有 @ 参考）

```
1999 年，中国北方小城的雨夜，红砖楼，昏黄的路灯，画面像一张褪色的老照片。写实真人电影，不要字幕，不要背景音乐。台词用标准普通话，逐字照说，没写台词的人不说话。「前情提要」后面的文字，只是让你了解人物此刻的处境和情绪，不要拍成画面，不要念出来，也不要出字幕；只拍「故事」里写的内容。每组的「场景布局」写的是这个地方的东西都在哪、哪边是哪边，所有人和东西都按它摆放，人往哪走也按它来，不要自己改动位置；场景布局本身不用单独拍。
前情提要：这是陈默的回忆。看到朵朵喘不上气，陈默想起自己六岁那年哮喘发作，父亲背着他冒雨跑出去救他。画面里年轻的父亲，就是现在住院的父亲。
场景布局：1999 年北方小城的一条街，下着大雨。路边是一排红砖楼，楼下有一段能避雨的屋檐，昏黄的路灯照着湿漉漉的路面。
故事：
镜头1：一个快四十岁、穿深蓝色工厂工作服的父亲，把六岁的儿子背在背上，双手托着儿子的腿，沿着街在雨里狂奔。儿子趴在他背上，张着嘴喘不上气。
```

### 第 19 组 病房·重逢（24 秒）

```
@图片1 是陈默，@图片2 是父亲，@图片3 是老周，@图片4 是朵朵，@图片5 是朵朵妈妈，@图片6 是病房（白天）；@音频1 是朵朵的音色，@音频2 是老周的音色，@音频3 是父亲的音色，@音频4 是陈默的音色。
前情提要：陈默刚给父亲看了随身的哮喘喷雾，父亲笑了。朵朵和妈妈也隔离结束了，来医院看外公，外公就是老周。老周和陈默只在电话里听过对方的声音，从没见过面：老周救了陈默的父亲，陈默救了老周的外孙女。父亲还不知道这些。
场景布局：医院双人病房，白天，阳光从窗户照进来。房门在一面墙上，窗户在对面墙上。两张病床并排放着，床头都靠着墙：靠门那张床是父亲的，床边立着心电监护仪；靠窗那张床是老周的，床上方装着骨科牵引架。两张床中间是床头柜，床头柜上方的墙上有呼叫铃。
故事：
镜头1：病房门又开了，朵朵妈妈推着轮椅从门口进来，老周坐在轮椅上，朵朵坐在老周腿上。
镜头2：朵朵看见站在父亲床边的陈默，从老周腿上滑下来，跑过去抱住陈默。朵朵喊：“叔叔！”
镜头3：陈默蹲下抱住朵朵，一抬头，和停在两步外轮椅上的老周对上了眼。
镜头4：老周说：“你就是默默？”陈默听出了这个声音，愣住了，不说话。
镜头5：老周和陈默看着对方，慢慢笑了。
镜头6：坐在床上的父亲看看老周，又看看陈默。父亲问：“你们认识？”
镜头7：老周说：“认识。”
镜头8：陈默说：“也不认识。”
镜头9：病房里的人都笑了，阳光落在两张病床之间。
```
