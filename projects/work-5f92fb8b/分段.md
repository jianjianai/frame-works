# 《默 默》分段提示词（Seedance 2.5）

全片 30 段，前后连着的合成 13 组生成，每组最长 30 秒。每次生成：复制【通用背景】，接上一组（从 @ 行开始复制，前情提要和故事都要）。闪回那组自带背景，不贴通用背景。参考图见 `角色.md`、`场景.md`、`物品.md`，写法见 `用法.md`。

## 通用背景

```
写实真人电影，中国现实题材，胶片质感，色调克制。2022 年冬天，疫情防控时期的一座中国普通城市：公共场所的人都戴口罩，防疫工作人员穿白色防护服；人们疲惫、焦虑，但彼此之间有克制的善意。不要字幕，画面里没有可读的文字，不要背景音乐。人物的长相和穿着完全按参考图；场景图只参考布局和陈设，时间和光线按下面写的；音频只参考说话人的音色。台词用标准普通话，吐字清楚，逐字照说，不加词、不改词，每句只由标明的人说；没写台词的人不说话；画外音响起时，画面里的人不张嘴；戴着口罩说话的人和画外音也一样清楚。每组里「前情提要」后面的文字，只是让你了解人物此刻的处境和情绪，不要拍成画面，不要念出来，也不要出字幕；只拍「故事」里写的内容。
人物：陈默；陈默的父亲；老周是父亲隔壁床的病友；朵朵和朵朵妈妈是母女。陈默和朵朵母女、老周都互不相识。
```

## 分组

前后连着的戏合在一组生成，最长 30 秒。标题括号里是这一组包含的段号，剪辑时按段号的顺序切开、交叉，见 `故事.md` 的「剪辑顺序」。

车站工作人员隔着起雾的护目镜说：“对不起，谁都不能走。”

天快亮了，病房里泛着灰蓝的光。靠门那张床上的父亲闭着眼睛，在梦里喃喃。父亲说：“默默，药带了没。”
老周拄着拐杖从自己床边挪到父亲床边，拿起父亲床头柜上的手机，屏幕上是一长串未接来电。
他按下回拨，把手机贴到耳边，不说话。
```

### 第 11 组 走廊·得救（第 22、23 段，20 秒）

```
@图片1 是陈默，@图片2 是朵朵，@图片3 是朵朵妈妈，@图片4 是酒店工作人员，@图片5 是酒店走廊，@图片6 是哮喘喷雾；@音频1 是陈默的音色，@音频2 是朵朵的音色，@音频3 是酒店工作人员的音色。

酒店工作人员走到陈默的房门口，看着门上撕开的封条，叹了口气。酒店工作人员说：“你出了门，得多隔离七天。”
陈默站起身，点点头。陈默说：“嗯。”
朵朵妈妈搂着朵朵站在对面自家门口，朝陈默深深鞠了一躬，不说话。

### 第 12 组 房间·天亮（第 26、27 段，22 秒）

```
@图片1 是陈默，@图片2 是陈默的房间；@音频1 是陈默的音色，@音频2 是老周的音色。

故事（时长22s）：

画外音，电话里老周说：“是默默吧？我是你爸病友。”陈默听着，不说话。
画外音，电话里老周说：“你爸夜里犯病，救过来了。”陈默捂住嘴，不说话。
画外音，电话里老周说：“这儿有我，你放心。”陈默眼泪掉下来，不说话。
陈默哭着说：“谢谢，谢谢您。”
清晨，门缝底下塞进来一张蜡笔画。
陈默从门边的地上捡起来，画上是一个穿灰衣服的大人牵着一个扎丸子头的小女孩，头顶一个大太阳。
陈默看着画，笑了，眼泪掉下来。
```

### 第 13 组 病房·重逢（第 28、29、30 段，30 秒）

```
@图片1 是陈默，@图片2 是父亲，@图片3 是老周，@图片4 是朵朵，@图片5 是朵朵妈妈，@图片6 是病房（白天），@图片7 是哮喘喷雾；@音频1 是父亲的音色，@音频2 是陈默的音色，@音频3 是朵朵的音色，@音频4 是老周的音色。
前情提要：隔离结束，陈默第一次来医院看父亲，父亲已经好多了。父亲总问陈默药带了没有，以前陈默总说自己早就不喘了，经过那一夜，他身上开始带着哮喘喷雾。朵朵和妈妈也隔离结束了，来医院看外公，外公就是老周。老周和陈默只在电话里听过对方的声音，从没见过面：老周救了陈默的父亲，陈默救了老周的外孙女。父亲还不知道这些。
故事（时长30s）：
隔离结束后的一个白天，阳光照进病房。陈默推门进来，坐在靠门那张床上的父亲看见他，眼睛亮了。
父亲问：“药带了没？”
陈默走到床边，从口袋里掏出一个哮喘喷雾，举给父亲看。陈默说：“带着呢，爸。”
父亲愣了一下，笑了，不说话。
门开了，朵朵妈妈推着轮椅进来，老周坐在轮椅上，腿上坐着朵朵。
朵朵看见陈默，从老周腿上滑下来，跑过去抱住他。朵朵喊：“叔叔！”
陈默蹲下抱住朵朵，一抬头，和两步外轮椅上的老周对上了眼。
老周说：“你就是默默？”陈默听出了这个声音，愣住了，不说话。
老周和陈默看着对方，慢慢笑了。
父亲看看老周，又看看陈默。父亲问：“你们认识？”
老周说：“认识。”
陈默说：“也不认识。”
病房里的人都笑了，阳光落在两张病床之间。
```
