# 反乌托邦 - 乌托邦P

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 需求
- 目标：抖音上能火的剧情 MV，看完让人感动、震撼或回味。
- 流程：先审简洁版剧情（2026-10-14 通过，见「剧情设定」）→ 分镜表（`分镜表.md`，2026-10-14 用户让按它做草稿）→ 视频草稿 → 草稿通过后精细化成片。每一步等用户确认再往下做。
- **草稿 = 整支视频**（用户定）：草稿把剧情、运镜、节奏、切点、光、文字、音效等全部视频要素都定下来，只有画面是简单的（简单的人物和场景）；精细画面留到最后一步。做草稿时不用检查画面。
- 画风：全新风格，**不用任何素材库**（角色、场景、道具、效果、音效都不用）。
- **经验暂时都记在本作品的文档里**（用户定）：不写进经验库，记在下面「本作品的经验」一节。

## 剧情设定（用户定，2026-10-14）
用户：「这个剧情非常完美……全部剧情都围绕这个剧情设定展开」。之后的分镜、画面、字幕和细节都从这个设定出发，不加和它无关的支线；要改设定先问用户。

片名（暂定）：《341个字》

大纲（用户通过的原文）：
> 这里的人一生只能说一千个字，说完就死，所以没人开口。每晚隔墙哼歌陪她的少年，今夜不哼了。她把剩下的341个字写成一首歌唱给他，唱完，数字归零。沉默一辈子的整座城第一次开口：活下去。原来说给别人的字，会变成别人的命。

### 世界规则
- 每个人一生只能说一千个字。手背上有一个数字（如「余 341」），说出一个字减一，归零就死。所以没人开口，整座城一片沉默。
- 说出口的字会发光，这是这个世界唯一的光。没人说话，所以城里没有灯，几乎是黑的。
- 哼歌没有字，不花命。
- 没人知道的真相：说给一个人的字，会变成这个人的命（听的人数字加一）。到「活下去」才揭开。
- 世界里没有一丝美好，每个人都绝望、孤独、一辈子沉默；但人们互相拯救。

### 人物
- 她：唱歌的人，手背「余 341」。她把剩下的字写成一首歌，字数正好等于她剩下的命。
- 他：隔壁的少年，和她隔着一堵墙做了一辈子邻居，从没见过面。他每晚隔墙哼歌陪她，前奏、间奏、尾奏的旋律就是他的哼歌。今夜不哼了：他想放弃，手里有一把小刀。
- 整栋楼、整座城沉默了一辈子的人。
- 伏笔里的妈妈和婴儿：前奏里妈妈轻声叫婴儿的名字，婴儿手背的数字多了 2。

### 已定的关键点（和歌的对应）
- 341 是数出来的：从「反乌托邦中的争夺」第一个字（15.93）到「希望这首歌能被记起」最后一个字，正好 341 个字。她手背的数字跟着每个唱出的字减一（按逐字时间），「起」唱完归零；112.0–113.5 原曲静音 = 她倒下。
- 唱出来的歌词就是她说出口的字：一个字一个字发着暖光从她嘴里飘出来，穿过墙缝。
- 互相拯救三层：他每晚的哼歌陪她 → 她用剩下的命唱给他 → 整座城把自己的字说给她，救回她。
- 唱第二遍的句子放新剧情：
  - 导歌2（79.56）：「请你等等我」这次是他的。他从墙缝看见她的数字一直在掉，捡起放下的那把小刀，挖墙去找她。
  - 标题句第二遍（55.98「即便我们都在这黑暗漫长的反乌托邦」）：镜头拉开，整栋楼的人都贴着墙在听。
  - 「活下去」×4（113.88 / 117.90 / 121.86 / 125.91）：他第一次开口 → 邻居 → 整栋楼 → 整座城，一次比一次多；她的数字从 0 往上涨。
- 伏笔：前奏里婴儿的数字多了 2，第一遍没人注意，看到结尾才懂；做「回看第几秒」的评论彩蛋。
- 尾奏（132–148）：他再哼那段旋律，她醒过来跟着哼。两人做了一辈子邻居，第一次面对面。

### 画风
- 全新风格，不用任何素材库的角色、场景、效果。
- 整座城几乎是黑白的，没有灯；全片唯一的暖色是说出口的字。

## 歌曲
- 120 BPM，每小节 2 秒（小节线 0.02 + 2n）；每句歌词约一小节。逐字时间来自酷狗 KRC（QQ 音乐动态歌词）。
- 112.0–113.5 原曲是静音的停顿，113.88「活下去」和整个乐队一起炸开；113.88–129.9 是全曲最响的一段。
- **用整首歌，不剪**（用户定）：作品 152 秒 = 原曲 0–152，作品时间就是原曲时间。原曲在 148.0 收尾，余音到约 151。
- 结构：前奏 0–15.9 → 主歌1 15.9 → 导歌1 23.6 → 主歌1后半 32.2 → 副歌1 39.4–56 →「即便我们都在这黑暗漫长的反乌托邦」56–59.6 → 间奏 64–72（前奏前半的旋律）→ 主歌2 72.1 → 导歌2 79.6（歌词和导歌1 一样）→ 主歌2后半 88.0 → 副歌2 95.4–112 → 静音停顿 112.0–113.5 →「活下去」×4（113.88 / 117.90 / 121.86 / 125.91）→「在这反乌托邦里」129.9–132.2 → 尾奏 132–148（前奏旋律弹两遍）。
- 唱两遍的歌词：导歌「但我还想做些什么 / 其实还想要说很多 / 请你等等我 ×2」、标题句「黑暗漫长的反乌托邦」、「活下去」×4。这些地方画面要放新剧情（经验库：唱过的句子再出现时最掉人）。
- 先试过的三种剪法都被否了：副歌1接副歌2后半（在一段中间接，「突兀」）、前奏直接接第二段（第一段歌词太少）、第一段 + 静音停顿接「活下去」（用户最后决定不剪）。
- 每句歌词的时间写在 project.ts 的镜头标记里。
- 剪歌原则（用户）：不能在一段的中间接到另一段，听过原曲的人会觉得突兀；接点放在伴奏里原曲本来就重复的地方。

## 草稿（2026-10-15 做出，等用户看）
按 `分镜表.md` 做成整支 152 秒（53 个镜头），分镜表里「大纲之外加的 8 个细节」都已做进去。画面是简单的侧面木偶和剖面楼，精细化时只换画法，不改已通过的剧情、运镜和节奏。

代码都在 `film/`（`visual.json` 里一个 scene 图层 `film`）：
- `lyrics.ts`：酷狗 KRC 的逐字时间（脚本生成，不要手改）。她手背的数字、嘴型、发光的字都按它走。
- `world.ts`：楼的剖面（7 列 × 26 行隔间，她在 (3,12)、他在 (4,12)、妈妈在楼上 (3,11)、老人在楼下 (4,13)、(2,9) 只剩一捧灰）、两人之间那堵墙（x 920–930：裂缝 → 挖的洞 → 111.45 塌开）、整座城和高架列车。
- `people.ts`：侧面木偶（两节反向运动学，手脚给目标点）、五官、哼歌的波纹、眼泪。
- `story.ts`：每个人的姿势关键帧（`HER_KEYS`、`HIM_KEYS`…）、小刀和纸、手背数字（`herCount`/`hisCount`…，按逐字时间算）、每句歌词放在哪（`PLACES`，世界坐标 w 或屏幕坐标 s）、邻居和整栋楼什么时候醒、什么时候喊。
- `direct.ts`：全片运镜是一条连续的世界镜头（`CAM_KEYS`，每个关键帧写了是哪一镜、什么情绪），抖动和小冲（`FX`），每一刻的环境光和暗角（`LOOK`），画面模式（回忆的纸 32.0–37.95、墙缝主观镜头 68.02–72.06、十四年前 88.45–92.05），各人的数字什么时候露出来。
- `film.ts`：渲染。世界 × 光照图（环境很暗，只有说出口的字和被字照到的地方亮）+ 发光的字 + 数字 + 颗粒、暗角、甩镜模糊；开场钩子字和结尾两个引导也在这里。
- 字体：`public/fonts/serif.woff2`（Noto Serif SC 700 的子集）。画面上的中文变了就运行 `node production/fetch-fonts.mjs` 重新下载。
- 音效：`audio.ts` 用代码合成（敲墙、拍墙、刀落地、砸墙、挖墙、碎墙、墙塌、吸气、轻敲、甩镜、点赞），`audio.json` 的「音效」音轨排了 45 个片段；master 加了 -1 dB 限幅（原曲本身就压得很满，叠音效会削波）。静音段 112.0–113.5 只有他 113.42 吸的一口气。

## 本作品的经验
（用户定：这个作品的经验暂时都记在这里，不写进经验库。）

### 不看画面时，用数字核对构图
- 什么时候用：用户说「不用检查画面」，或者镜头多、要先确认每镜主体都在画面里。
- 做法：用 esbuild 把 `film/direct.ts`、`story.ts`、`people.ts` 打包成 node 脚本，按每个镜头取几个时刻，算出她的头、他的头、手背数字、发光的字在 1080×1920 画面上的坐标和字号（世界坐标 → 镜头），标出出画的。这次查出两处：一句歌词左边出画、墙缝主观镜头的缝放不下「余 161」。
- 好处：所有镜头都是同一个世界坐标里的一条连续运镜，上一镜的终点自然就是下一镜的起点；位置都是算出来的，可以不看画面先核对。

### 给歌设计剧情：让「唱这首歌」本身成为剧情（用户一稿通过：「这个剧情非常完美」）
- 什么时候用：用户只给歌和方向（「全新世界观」「感人、震撼」「人们互相拯救」），要先交 50–100 字大纲时。
- 做法：
  - 先把歌拆开：逐句列出时间、每句字数、哪几句唱两遍、哪里静音、哪几段是纯器乐。
  - 从歌词里反复出现的东西定一条世界规则，让主角唱这首歌就是剧情里的行动，而且要付代价（这首歌一直在说「说很多」「词句」「歌唱」「沉默」「光」→「一生只能说一千个字；说出口的字是唯一的光」）。
  - 规则一句话讲得清，直接当开场钩子字；规则里藏一个反转（「说给别人的字会变成别人的命」），开头给一个第一遍看不出的伏笔，结尾揭开，做「回看第几秒」的彩蛋。
  - 把歌的结构做成剧情机关：字数做倒计时（第一句到静音前正好 341 字）；原曲的静音停顿 = 剧情的死寂，后面的爆发 = 反转；纯器乐段 = 剧情里没有字的声音（哼歌）；唱两遍的句子换成另一个人的心声，或一遍比一遍规模大。
  - 「互相拯救」分层，每层换一个方向：他用哼歌陪她 → 她用命唱给他 → 所有人把字说给她。
  - 大纲后面附 4–5 条「怎么卡这首歌」（带秒数），用户一眼看出剧情是贴着歌长出来的。
