## 人物动作（用户 2026-10-18：「头发和风的循环动画没接入，很死板；动作很僵硬，完全不行」）
- **不用素材库「剪纸角色」的动作预设**（POSES、jumpGrabKeys、kneelGiveKeys、run 的步子……，用户 2026-10-18：「预设有问题，做出来的姿势都很别扭」）。所有姿势在 `lib/poses.ts` 自己按关节角度写（手臂按画面里的方向写，自动加上身子前倾），检查页 `sheets/前奏姿势.ts`（每个姿势单独站在地面上，红点是近处手掌、蓝点是前面那只靴筒口）。素材库只用它的画法和动作引擎（figurePose、gait、figure-motion 的插值）。
- **前后脚**（用户 2026-10-18：「动作方向反了」）：朝左时画面左边那只脚在前、右边那只在后；朝右时画面右边那只在前。站、刹停、蹲、跳、落地、弯腰、跪都这样。素材库的 L 是靠近镜头的那条腿，3/4 时它本来在身后那侧，所以姿势表里一律 R（远处那条）在前、L 在后；跑步最后一步也让 R 落地刹住。
- 她穿铁靴：脚放平时小腿最多前倾约 17°。单膝跪要前腿 R 立着、后膝 L 着地、后脚小腿和靴子一起翘起来靴尖点地，才像跪（L 在前时两腿交叉，像蹲在靴子上）。
- 周磊是短发：失重 ≥ 0.5 时头发画成竖起的尖（像猫耳朵），所以飘着只给 0.15；|face| 在 0.2…0.45 之间头发会画成一根长刺（素材库的毛病），不停在这一段。他的姿势一律 ground: false（根由脚踝 / 坐的位置决定），坐在地上时胯放在离地约 45（lift −235），膝盖立起来、脚收在身前踩地（这个角色脚踝离地 65：腿的角度要让脚踝正好离地 65，见 `lib/poses.ts` 的 SIT）；远处的手搭在远处膝盖上（垂下来会伸到她靴子上）。
- 朝右的人（小石头）用脚钉地算出来的根的 x 要取反（整套镜像）。
- 所有人都要给风（`wind`，街上 0.85、天上 1.1，往画面右吹：她朝左，头发围巾往后飘）：素材库的头发、围巾只有在有风或失重时才按 4 秒循环飘，风是 0 就是死的。
- 走、跑的关键帧 ease 用 `SMOOTH`（平滑曲线、速度连续穿过关键帧，根在关键帧之间也平滑走），站着那只脚匀速往后退、前脚落地后后脚再蹬一下（用户 2026-10-19：「走路一顿一顿的，头发也是」）。
- 跑（用户 2026-10-19：「跑步的动作看起来一顿一顿的」）：有腾空，根不按钉住的脚反推，按 dx 匀速走；姿势表里 ground: false、胯高直接给，站着那只脚在落地 / 踩实 / 蹬离地三个时刻按反算放在地上、相对胯退的距离正好等于这个速度走的距离（脚几乎不滑）；手臂和腿反着摆、比腿早 0.3 步（抵消手臂弹簧慢半拍）。**刹住那一帧要写回 `ground: true, lift: 0`**：关键帧没写的参数接着上一帧，忘了写的话刹车到结尾她全悬在地面上（跪着高 138）。
- 主要人物用 `lib/motion.ts` 的 `live()` 放关键帧：手臂、脖子按弹簧跟随（飘着的人连腿和整个人的转），再叠连续的小动作（飘着时四肢慢慢摆、哭时肩膀一抽一抽、站着重心晃）。不要直接用 playMove 在几个姿势之间硬插。
- 表演要有预备和余势：砖落进手里 = 手一下坠下去 → 另一只手托住 → 捧到胸口哭 → 抬头哭着笑。公文包是松手滑下去的（用户：「他不用动」），松手以后手慢慢浮起来、闭上眼往上飘。
- 镜头跟人身上的点用 `smoothTrack`（弹簧追），不要死盯，不然手坠一下、扔出去的动作全被镜头抵消。
