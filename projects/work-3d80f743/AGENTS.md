- **姿势要有动势**：跑的时候身子前压 18°、上臂前后摆 ±50°、肘一直弯着（往前的手到下巴、往后的手在胯后）；蹲是拉满的弓（大腿放平、胯往后坐、身子前压、手甩到身后、仰头盯着目标）；跳是全身弹直、手往上够。
- **前后脚**（「动作方向反了」）：朝左时画面左边那只脚在前；姿势表里一律 R（远处那条）在前、L 在后；跑步最后一步也让 R 落地刹住。
- 她穿铁靴：脚放平时小腿最多前倾约 17°（胯 + 膝 ≥ −17）。单膝跪要前腿 R 立着、后膝 L 着地、后脚小腿和靴子一起翘起来靴尖点地；前腿收着（KNEEL），只把大腿放低会把人顶高、后膝离地，要前膝抬高、小腿前倾。lift 参数最多 600，跳得更高时把根整个往上挪（`jumpExtra`）。
- 周磊是短发：失重 ≥ 0.5 时头发画成竖起的尖，飘着只给 0.15；|face| 在 0.2…0.45 之间头发会画成一根长刺，不停在这一段。他的姿势一律 ground: false，坐着时胯在离地约 45（lift −235），膝盖立起来、脚收在身前；远处的手搭在远处膝盖上。
- 朝右的人（小石头）用脚钉地算出来的根的 x 要取反。所有人都要给风（街上 0.85、天上 1.1，往画面右吹）。
- 她的围巾垂下来那头**全程压在手臂上面、不被手臂挡**（用户 2026-10-19：「改成全程不被手臂档就行」）：`scenes/act1.ts` 里她的动作底子写 chestL / chestR: "under"（素材库的参数：over 手臂压在围巾上、under 手臂在围巾后），姿势里不要再单独写 over。原来按前臂横没横在胸前自动判断，伸手进靴筒、走路摆臂时会在手臂前后来回翻。
- 走、跑的关键帧用 `SMOOTH`；跑的根按 dx 匀速走，刹住那一帧写回 `ground: true, lift: 0`。
- 主要人物用 `lib/motion.ts` 的 `live()`：手臂、脖子按弹簧跟随，再叠连续的小动作（飘着时四肢慢慢摆、哭时肩膀一抽一抽、站着重心晃、跪着喘气）。表演要有预备和余势。镜头跟人身上的点用 `smoothTrack`。
- `live()` 里同一时刻的姿势只算一次（figurePose 每次都要把全部参数校验一遍，很慢），头发甩动取的前一个时刻放在 1/30 秒的格子上，播放时和前几帧共用；改动作代码时别把这些缓存拿掉（拿掉以后全城那几秒每帧 60 多毫秒）。
