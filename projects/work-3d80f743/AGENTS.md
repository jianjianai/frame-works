# 反乌托邦 - 乌托邦P

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 需求
- 目标：抖音上能火的剧情 MV，看完让人感动、震撼或回味。
- 用整首歌 152 秒讲完整个故事（用户要求「长达两分钟整首歌的剧情」），不剪歌。
- 全新画风，**不使用任何现有素材库**，全部重新画。画风要**大众能接受、不压抑**（用户 2026-10-15 否掉了灰黑剪影 + 重暗角的第一版：「过于压抑」）：柔和的扁平插画 + 细颗粒，粉橙淡紫的天、发光的「白」、粉白色的落灰像雪，人物有表情、每人一个标志色，夜是靛蓝不是黑，暗角很轻；暖光 = 被人放在心上。颜色在 `yinli/palette.ts`。
- 故事《引力》：世界观、人物、五幕故事和按歌词时间排的剧情表都在 `故事.md`，分镜和画面以它为准；改剧情先改 `故事.md`。
- 先做草稿：草稿定下剧情、运镜、节奏、音效等全部要素，只是画面简单；确认后最后一步才精细化画面（用户 2026-10-15）。
- 开场（前奏 0–15.9）是用户定的，一镜到底（`yinli/intro.ts` 一个镜头）。用户第三次重定的顺序（2026-10-15）：**一个人化成灰（0–1.5 秒内）→ 整座城 → 一个飞起来的人（5 秒内）→ 她救下他 → 城里人和她打招呼**；「运镜是草稿的灵魂，也是整个视频的灵魂」。之前「首帧城市全景再推过去、停留、化灰」「跟着一粒灰穿雾落到街上」两版都被否了（「太硬，没有灵魂」「还是不行」）。现在的做法：
  - 0–0.513 首帧就贴在光里的女人身上（张手、闭眼笑、眼泪往上飘、脚踝上割断的红绳），设定字在她脚下；镜头屏着气几乎不动。0.513 她碰到光化成灰，镜头被光推开、歪着的画面回正。
  - 1.15–2.95 往后拉出整座城（远处还有人在飘、又一个在光里一闪），停一下；2.95–4.013 往下摇、越扎越快，4.013（第 3 小节）落在飘着的周磊身上。
  - 4–5.5 慢慢逼近；打伞的人、称重员低着头从他底下走过（称重员不停、不抬头：全城低头，高潮才抬头）；画外的「咚」越来越近越急。5.55 公文包滑下去，镜头跟着坠，6.013（第 4 小节）她的铁靴砸在公文包旁边——她的第一个镜头。
  - 镜头从铁靴抬到两人同框，她一蹲，7.24 起跳、7.59 抓住脚踝，带着惯性落下，8.013（第 5 小节）砸裂石板。**动作要有物理惯性，不要跟着音乐一下一下硬拉**。
  - 8.3–10.9 掏砖「活下去」放进他手里：**不切镜头，用情绪运镜**（落到靴子上、跟着砖推近、越推越慢，再舒一口气）。
  - 10.9–15.9 她从周磊身后走开（画在他后面，不穿过他），然后**只和两个人打招呼**（用户：「打招呼 3 次太多了，改成和 2 个人就行」），镜头每次把两个人框进同一个画面：抬上去框住窗后举杯的老钟 → 小石头跑过来停在她前面一步远（太近会被她挡住），她弯腰摸头，他跑回妈妈身边转身朝她挥手（她不从他身前走过）→ 镜头升起来，`INTRO_END` 交给主歌一第一镜。妈妈只是背景，不鞠躬。
  - 「城里都说，她是最沉的人」：6.55 起（镜头抬过周磊的头以后）一直到 15.9，放在画面上方（y=260），不压人物；结尾的镜头高度让头顶的网停在字幕上面。
  - 用户要我多发挥：用户给的是方向，镜头怎么切、动作怎么带、时机卡在哪里由我判断，不要照字面硬套。
  - 不用称重站、斤本这类「用秤和字讲轻重」的东西（用户：「太奇怪了」）。
- 后续剧情用户在一段段补充（2026-10-15：一家卖超级大哑铃的店开门了，哑铃用来压住绝望的人；绝望的人大多带着小刀，割断锁住自己的绳子，飞升到天上化成灰）。已定：主歌一第一镜（15.9–17.82）是她住的那栋楼脚下的哑铃店，很多人在买，**穿紫衣服的女人（千斤的妈妈）买走最大的那只**（门口展台上），抱起来很沉、膝盖一直弯着；原来的收灰车、灰锭全部换成哑铃（`props.ts` 的 `dumbbell()`、`dumbbellShop()`），锁在千斤脚踝上、掉下天井的都是这只。买哑铃的路人不穿紫色，好让她一眼认出。
  - 17.82–21.84（一个镜头，在外面不在屋里；**和哑铃店不是同一个地方**——用户：「买哑铃和给哑铃不是同一个地方，需要切换地点」——是她家门口一条安静的小街，门口摆着爸爸的空鞋）。换地方用匹配剪辑：上一镜推到妈妈怀里的哑铃上，这一镜同一只哑铃在画面同一位置、叠 0.3 秒溶解，背景换成她家门口，镜头退开。穿红衣服的女孩（千斤，标志色改成红）飘在半空，脚踝上一根红线牵在路边的铁桩上；妈妈抓住红线一把一把把她拽下来，用铁链把哑铃锁上她的脚踝（20.013「咔」），解开红线，哑铃坠着她落地，妈妈把哑铃放进她怀里走了。原来九十八层屋里的两镜删掉了。
  - 21.84–23.94 删掉了「看天井、发卡插锁」那一镜，同一个镜头接着拍千斤（用户：「把运镜给到红色衣服女生，并做一个情绪运镜。紫色衣服女生走之后，红色抱着哑铃依然飘起来」）：看妈妈走远 → 低头看哑铃 → 抬头看天，镜头极慢推近脸、四周暗下来；23.013 脚离地，抱着哑铃飘起来，镜头往后往上退，爸爸的空鞋留在画面底下。所以 `s06` 现在是 17.82–23.94。
  - 23.94–31.92 高空（用户 2026-10-15：「镜头切到高空，红色衣服女孩已经飘了很高，之后给情绪运镜，她解开了锁，哑铃掉到地上。之后主角从楼顶跳下，把她救下，之后又给了她一个写着活下去的砖，这个砖很重，红色衣服女生拿着它不再往上飘」）。`verse1.ts` 的 `s07`（23.94–25.77）和 `s08`（25.77–31.92，一镜）：
    - 世界：全城最高那栋楼在 x=0（她住在楼顶，`TOWER_TOP`），旁边矮一点的楼 B 在 x 720–1500（楼顶 `HIGH_RB`，由两人落地的位置反算），千斤在两楼中间的楼缝里（x≈615）。
    - 换场用溶解：千斤在画面同一位置，背景从家门口换成高空（更远的取景，看得见白、两栋楼顶和楼顶上的她）。
    - 情绪运镜：慢慢凑近她（低头看城、抬头看白）→ 拔黄发卡，镜头直直落到锁上，25.013「咔」→ 松手，镜头追着哑铃顺楼缝坠到街上，25.77 砸地 → 镜头甩上去，掠过往上飘的千斤，落到楼顶边上往下看的她 → 退两步、冲、27.78 跳下去，28.16 半空抱住（按落体算出抓住的时刻）→ 最沉的抱着最轻的，往下坠一下被托住，慢慢飘，镜头推近 → 29.73 退远看两栋楼和白 → 31.3 落在楼 B 楼顶。
    - 30.1 落在楼 B 楼顶，她搂着靠在肩上哭的千斤（千斤还总往上浮）。**这里不给砖**（用户：「这里不给砖头」）。
  - 导歌一 31.92–39.99（`pre1.ts`，用户 2026-10-15 逐句定的）：「两块五的签字笔」她在自己家里灯下写砖（32.65 近景笔和价签）→「东拼西凑的词句」镜头滑过一屋子写着各种让人活下去的话的砖（`WORDS`）→「妄想用它拯救你」**回到之前的楼顶**（用户：「场景不变，是回到之前屋顶的时间段」），她从靴筒里抽出一块「活下去」给千斤，**接住的那一下很沉**：手一坠、身子「咚」坐回楼顶、头发落下，抱住砖（`pre1.ts` 的 `girlRoof`/`qinRoof`）→「顺便拯救我自己」夜里脱掉铁靴，自己飘起来，睡到天花板上倒钉的床上（脚绳拴在椅子腿上）。
  - 她的屋子（`sets.ts` 的 `qinRoom`）**地上没有床，只有一把椅子**（用户：「这里地上不用床，一把椅子」，`world.ts` 的 `chair()`，脚绳拴在椅子后腿上 `BEDPOST`），天花板上倒钉着一张床；`qinFloatSleep(t, 1)` 就是睡在那张床上（挪到了 `pre1.ts`，`chorus1.ts` 转出）。副歌一 39.99 的反转改成她已经睡在天花板上，镜头退出窗外。
  - 副歌一 39.36–43.92（`yinli/web.ts` 一个镜头，跨第一幕和第二幕：`webShotA` 在 act1、`webShotB` 在 act2，同一个 `webDraw`）。用户：「只因为……一个人向上飘，之后被绳子拉住；困在……向后，展示网，震撼」。做法：溶到窗外 → 镜头贴着一个睡着的人往上飘（他在画面下方，头顶露出白，沿途掠过已经挂在天上的人）→ 41.013 红绳绷直把他拽住（镜头冲过头再落回、震一下）→ 吊着低头看绳、抬头看白 → 41.94 往后拉到整座城：全城的人拴着红绳飘在楼顶和白之间，绳子缠成一张网，他的绳子也被缠进去，最高那栋楼在正中。城压矮让出天空。原来「早上把自己拽下来」那一镜删了，「没人知道，她飘得最高」的字幕也去掉了。S16 压到 39.36 结束。
- 母题：她靴子里塞满了砖，每块都写着「活下去」（夜里写给自己，白天送给要飘走的人；她自己的砖是灰白的，到了别人手里才变暖）；小石头的话是「明天见」（「妈妈，明天见」、结尾写在她那块砖背面的「秤砣，明天见」）。砖画在 `figure.ts` 的 `stone()`。

## 草稿结构（yinli/）
- 五幕各是一个 scene 图层（visual.json 的 act1–act5，模块 `yinli/act1.ts`…`act5.ts`），镜头按歌里的绝对秒数写：前奏 `intro.ts`、主歌一 `verse1.ts`、导歌一 `pre1.ts`、副歌一 `chorus1.ts`、间奏 `inter1.ts`、主歌二 `verse2.ts`、导歌二 `pre2.ts`、副歌二 + 静 `chorus2.ts`、活下去 `finale1.ts`、尾声 `finale2.ts`。
- 公共：`core.ts`（设计坐标 1080×1920、缓动、镜头 kcam、溶解/甩镜模糊、文字、makeAct；镜头的 `xin` 是开头交叉溶解秒数）、`palette.ts`（全片的颜色和每个人物的标志色）、`figure.ts`（彩色扁平人偶：描边、轮廓光、表情；关节角度或手脚目标点）、`world.ts`（白、灰、地面、城、网、称重站、天井、屋子、电车）、`props.ts`、`sets.ts`（街道、她的屋子）、`chain.ts`（人链）。
- 世界坐标：地面 y=0，往上为负；白的下沿 y=-9000；楼层 300；她那栋楼在天井剖面里 28 层。
- 落灰 `world.ts` 的 `ash()` 在世界坐标里落（远中近三层视差），不贴在屏幕上（用户：「镜头移动时雪花像是贴在屏幕上」）。
- 屏幕上的字用 `public/fonts/yinli-serif.woff2`（Noto Serif SC 子集）；改了画面上的中文要重新生成子集。
- 音效：`audio.ts` 的 `sfx` 模块合成（她的「咚」、灰锭、锁、敲门、白的嗡声等），audio.json 里「脚步」「动作」「白」「环境」四条音轨，时间对齐画面里的事件。
