# 分镜表

时间是作品时间（秒）。拍子 b(k) = 0.013 + 0.5k，小节线在偶数秒 .013。歌词的字是酷狗逐字歌词（KRC）的时间。地点见 `地图.md`。第一幕（0–16）已经做完，见 `AGENTS.md`。

## 第二幕「千斤」（16–40 秒：主歌一 + 导歌一）
故事：最高那栋楼脚下的哑铃店；千斤的妈妈买走最大的哑铃，用铁链锁在女儿脚踝上；千斤抱着哑铃又飘了起来，在高空用发卡打开锁、扔掉哑铃；沉沉从楼顶扑出去在半空抱住她，两个人落在旁边那栋楼的楼顶上，沉沉给了她一块「活下去」；夜里，沉沉在灯下写砖，脱掉铁靴飘到天花板上的床里。

**一条竖线**：这一幕一路往上走——从楼脚的店，到门口两层楼高的千斤，到巷子顶上的白；最后落到全城最高的那间屋子，最沉的人自己飘得最高。

**接法**：第一幕的片段延长到 16.53，16.0–16.51 从停在整座城上的那一刻顺着最高那栋楼扎下去，第二幕从落定那一帧接着。

**音乐**：16–20 鼓停，只有人声和琴（轻）；20–24 底鼓每拍一下；24–32 贝斯进来，底鼓落在每小节第 1、3 拍（满起来）；32–39.5 导歌，底鼓每秒一下（像心跳）；39.5 起往副歌推，40.0 副歌。

### 伏笔和对称
- 千斤松手以后的样子 = 片头光里的女人（张手、闭眼、眼泪往上飘）：观众以为她也要化成灰，这一次有人接住了。
- 锁在脚上的是妈妈的爱：压得住身子，压不住人；打开它的是她自己的发卡。妈妈背对着窗在哭，女儿从窗前飘过去——两个人都绝望，谁也够不着谁。
- 她家楼顶离白只有一个人高：她每天收床单的地方，抬手就是白。
- 靴筒：夜里塞进去的砖，就是白天抽出来给人的砖。36.0 和 38.0 都用同一只靴子接镜头：前一次把分量给了别人，后一次她自己没了分量。
- 砖在她自己屋里是灰白的，放进别人手里才暖。
- 她脱下靴子就飘起来（第一次让观众知道她的秘密）；副歌二她在半空脱下靴子给小石头，是同一个动作。
- 这一次她从楼顶扑出去抱住人、落了下来；副歌二她从窗口跳下去抱住小石头，两个人还是往上飘——同样的一跳，结果相反。
- 千斤挣着够白、被攥住手腕、最后搂住她才落下来：抱住她的人有了分量，是她自己选了留下（第一句挣，第二句搂住）。

### 要做的东西
- 人：千斤（16 岁，红毛衣、黄发卡、齐肩短发）、千斤的妈妈（紫外套、盘发）都在素材库 CAST 里；哑铃店里的人用路人。沉沉夜里在家脱了外套、手套和围巾，脱了靴子穿白袜子（光脚的脚趾近看像爪子）。
- 场景：哑铃店（铺面、铁架、哑铃、展台、招牌「哑铃」）、千斤家那栋高楼（一楼的门、铁桩、门边的窗和窗里的妈妈）、巷子、两栋楼的楼顶、夜里她的屋子（台灯、桌椅、一排排砖、带防飘栏的窗和窗外的白、倒钉的床、脚绳和地上的铁环）。
- 道具：哑铃、铁链、挂锁、红线、黄发卡、签字笔、砖上的字（龙藏体，她的手写）。
