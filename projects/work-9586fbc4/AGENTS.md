## 剧情（方案 A《瑕疵：0》，已确认）
- 一句话：脸上有一大块红色胎记的男生，把家里所有镜子都蒙上了。网上聊了很久的“白猫”一直想看他的脸，他发了一张 P 掉胎记的照片。见面那天才发现，她是班上那个从不笑话他、一直在画画的女生。
- 钩子（首帧完整）：他正把报纸糊上浴室镜子，大字「她说，想看看我的脸」。第一人称（会被当成作者本人，用户已知）。
- 反转（32.5 秒 “I have a question”）：她翻开速写本，每一页都是他，胎记都画成一片红色小枫叶；最后一页是他发的 P 图，胎记被她画了回去，旁边写「为什么要 P 掉它？」。
- 兑现：她在自己脸上也点一片小枫叶，他笑出声；开头红笔标的「瑕疵」被划掉改成「她最喜欢的地方」。
- 结尾：回到开头那面镜子，他撕下报纸（首尾同一句 “Put up all the mirrors”，意思反过来）；镜子角贴着她画的白猫和黑猫（封面）。最后 2 秒叠「点赞的人，在喜欢的人眼里都是零瑕疵」和「回看：她第一次出现在第几秒？」（答案：教室后排，约 5 秒）。
- 头像：她是白猫，他是看不清脸的黑猫（呼应封面）。她书包上挂白猫挂件。

## 制作
- 代码：素材库 s0rrow 的 draw / kid / people 拷进了 `scenes/lib/`（从素材库直接 import 时引擎路径对不上，类型检查过不了）。draw.ts 改了 FONT_DIR、BPM、BEAT0、FONT_FILES，加了 rootScale()。以后要用 phone / chat / hand / screens / sfx-audio 也照此拷贝；本作品的场景文件 `scenes/lib/sets.ts` 和素材库的 sets.ts 同名不同内容，拷库里的要换个文件名。
- 胎记：`scenes/lib/story.ts` 的 `birthmark()`，在他左脸（正面看在画面右侧），葡萄酒色不规则斑块加小斑点；`MARK_AT` 是红笔圈的中心。红笔字用 `redNote()`（Long Cang）。
- 字体：Google Fonts 按用字子集化，放在 public/fonts（来源记录在 public/production/*.css）；新增文字要补取子集（见 draw.ts 的 FONT_FILES 注释）。
- 手机：`scenes/lib/phoneui.ts`（从素材库 phone/chat 改写，没有整个拷）——深色聊天（她的头像白猫、他的是背对镜头的黑猫）、「已拒绝」通话记录、照片气泡、视频来电（前置摄像头里是他自己的脸，镜像，胎记在画面左边）、美颜 App（祛斑滑条、「瑕疵：1 → 0」）、「发送给」对话框、触点。他发出的自拍 `selfie(c, w, h, mark)`，mark=1 是有胎记的原图（反转时她画回去的那张就用它）。聊天内容和时间在 `scenes/night.ts` 的 `hisChat()`，第二幕接着用。手机近景：缩放 1.0、顶部在标题胶囊下方（cy≈905），键盘一直开着让最新消息在歌词上方。
- 客厅：`scenes/lib/living.ts`（面对沙发：沙发上方的圆镜子糊着报纸、左边落地灯、右边窗和月亮、边几上的闹钟 `clock` 参数），夜景光 `livingNight`，手机镜头的虚化背景 `livingBokeh`。第二幕沙发、闹钟转到天亮用它。
- 第二幕 `scenes/act2.ts`（回复、沙发、夜里到天亮、客厅镜子前试三次；`disguise()` 遮瑕膏/口罩/墨镜/帽子在 story.ts）。第三幕 `scenes/act3.ts` + 天台布景 `scenes/lib/roof.ts`（书包和白猫挂件 `backpack()`）。第四幕 `scenes/act4.ts`（速写本：灰度速写 + 红色枫叶 `mapleLeaf()`，P 图页，锁屏，红笔改字，「这下一样了」）。第五幕 `scenes/act5.ts`（撕报纸、猫画、脸上的小心心、双击点赞、两条结尾提示，提示画在光效之后）。各幕都用 `designScene(options, 起点, …)`，图层在 visual.json 按小节线接。
- 开头四个镜头（act1 的 shot1–4）：转场都是运镜——甩镜用 draw.ts 的 `smear()`（任意方向动态模糊，快门 1/48），推进/冲镜头用 `zoomBlur()`（径向模糊），推进床单到白场再从白场出来。走廊布景在 `sets.ts`：`HALL`、`hallRoom`（墙纸、护墙板、地板、窗和纱帘、壁灯）、`hallGlass`/`hallMirrorFrame`/`hallMirrorShadow`、`hallLight`（灯光+月光）、`hallPlant`；床单 `clothSheet(q)`（四角+顶边拱度+侧边+下摆飘动），act1 的 `SHEET_KEYS` 关键帧用 Catmull-Rom 插值；`hallwayNight` = 盖好床单后的同一面墙（③④的虚化背景）。④ 用 `grade()` 褪色、红笔画在褪色之后。音效：fxWhip 1.12、fxSheet 1.567（新合成的 `sheet`，0.5s 处落地闷响对准 2.067）、fxWhite 2.3、fxRush 3.88、fxHit 4.099（去掉了两声胶带）。
- 教室：`sets.ts` 的 `classroomBack`（地平线 y 520；坐着的人尺寸 s → 头心 y = 520 + 264·s、桌子前沿 = 头 + 300·s）和 `classroomSun`；act1 的 `shotClass`（三层景深：后排 blur 1.8 → 他和身后两个同学 → 前排 blur 9；`classView` 一个运镜、`classLayer(c, v, 深度)` 分层视差，`focus` 做转焦：后排 1.8→0.3、他那层 0→2.2；捏住胎记的手 `classHim` + `coverHand`：前臂和手画在桌子之后、裁到桌前沿以上，单独叠一层冷色），戳人的食指 `indexFinger()`，放在桌上的前臂用裁剪在桌子之后重画一遍。
