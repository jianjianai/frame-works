在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 需求
- 抖音剧情 MV，目标百万播放、点赞评论率优秀；开头必须抓眼球；有看完能回味的剧情；中英双语歌词。
- 音乐起点由用户定：从第一句主歌开始（素材 offset 16.332）。时长 46–60 秒（用户先放了整首 73 秒，看完说「这个时长对这段剧情太长，显得拖沓」）→ 现在 57 秒。改音频前先读 audio.json。
- 手机近景只画手机、不画手（用户：「手太难做就不做了」）；手机 1.0 倍，拇指按下处用半透明触点表示。
- 顶部标签只写和画面对得上的：钩子缩小后是「他的视角」，28.10 翻成粉色「她的视角」，45.05 翻成「第二天」，54.76 淡出。原来的「她的第 37 个「嗯」」「她的视角 · 删掉的第 37 段话」和结尾字幕「这一次的「嗯」/ 后面什么都没删」用户说「非常奇怪，和视频一点都不吻合」，已改掉/删掉；结尾不加金句。
- 结尾引导（用户要求「互动率高的引导，和点赞的引导」，54.89 起叠在最后的街景上，留到最后一帧）：点赞——屏幕中间模拟双击（两圈波纹 + 大爱心弹出、甩出小爱心，随拍跳）+「点赞的人，喜欢的人都会秒回你」（呼应剧情里的秒回）；评论——底部卡片「回看第 1 秒：「对方正在输入...」闪了几次？」+ 黄字「答案打在评论区 ↓」。
- 闷音不要太闷：低通 520Hz 用户说「影响听感」→ 1500Hz、q 0.5，交叉淡入。
- 用户要求把素材库的「建模」（角色、道具画法）优化得更精细 → 已重画 kid/people、新增女主（kid.ts 的 who: "girl"）、聊天界面 chat.ts、学校/房间场景，并写回素材库 s0rrow。

## 节奏对齐（卡点，2026-10-07）
- 用户说视频已经完美，最后把音乐节奏对齐：所有硬切和带音效的动作都在八分音符网格上（`beatAt(k)` 正拍、`beatAt(k + 0.5)` 反拍，一个八分音符 0.256 秒），全部写在 `timeline.ts` 的 `EV`；audio.json 的音效 start 等于对应事件时间（取到毫秒）。各镜头里原来写死的时间常数都改成了相对 EV 的偏移。
