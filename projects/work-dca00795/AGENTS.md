# [v2.1]反乌托邦 - 乌托邦P

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 需求（用户 2026-10-16）
- 这是《[v2草稿定稿]反乌托邦 - 乌托邦P》（work 3d80f743）的**成品**，目标是电影级交付。
- 草稿只参考**叙事、剧情、时间点、分镜和节奏**（故事稿：3d80f743 的 `故事.md`），**不参考它的代码**，按剧情需要重写更好的代码。
- 不只做竖屏：代码要留出横屏适配的口子（镜头按画面比例取景，不把 1080×1920 写死在场景里）。
- 场景、动作、运镜、情绪、人物全部按剧情重新设计；运镜用**情绪运镜**（先想情绪再做镜头），每个镜头都要推进剧情、带情绪或带来震撼，不放无意义空镜。
- 人物简单线条、表情清晰、动作流畅、有美感，每个人有自己的特点。画面和配色跟着音乐的感觉走。
- 不死磕分镜表和草稿：有更好的表达（剧情更通顺、情绪更高、画面更美）就大胆改。
- **一个镜头一个镜头做，做完一个就核对**，没问题再做下一个。
- 第一步：先做人物设计，用户审核通过后再继续。

## 人物：现成的 2.5D 模型 + 换装（用户 2026-10-16）
- 用户：「你去网上找现成的 2.5D 模型，把身体骨架保留，替换衣服发型装饰这些，别自己搓了。」之前手画的 2D 人物（日系大眼睛 + 西式工装；之后照《罗小黑战记》设定图一处一处改、再照参考图描轮廓）侧面始终不对，全部作废。
- 用户：「都已经找现成模型换衣服了，就不要参考罗小黑人物的设计了。自己设计一套更好和剧情需要的服饰。」「小石头是男生不要用女生的模型。」→ 服装按剧情里的城（人人铁底鞋、衣服缝铅、落灰、穷人家手缝的东西）重新设计，小石头换成男性底模。
- 底模：VRoid Studio 的官方样例模型（VRM 0.x，就是 glTF，改名 `.glb` 放在 `public/models/`）。来源 OpenGameArt「vroid studio cc0 models」（opengameart.org/content/vroid-studio-cc0-models）；模型自带的许可：Base_Female/Base_Male/HairSample_* 是 CC0，其余是 VRoid Hub「全部允许」（个人和法人商用、修改、再分发都允许，不用署名）。材质名 F00 开头是女性身体，M00 是男性。
  - 秤砣：`Sendagaya_Shino`（千駄ヶ谷篠，女）。小石头：`HairSample_Male`（CC0，男）缩成小孩。
  - 其他底模留着做配角（周磊、千斤、老钟、阿满、妈妈们）：Base_Male、Sakurada_Fumiriya（男）、Base_Female、HairSample_Female、AvatarSample_D（女）、AvatarSample_E（小女孩）。
- 画法是三渲二：卡通材质两阶明暗（脸不分明暗）、等宽描边（背面外扩，按画面像素算宽度）。
- 代码：
  - `rig3d/vrm.ts`：读模型（转成面朝 +Z）、`toonify` 换卡通材质和描边、`hide` 按材质名隐藏原来的衣服、`colorize` 按亮度换色（头发染黑、眼睛染深褐、眼线改深褐、把身体贴图上画的指甲油改回肤色）、`pose`（每根骨头相对静止姿势的欧拉角）、`express`（VRM 表情：joy、fun、sorrow、angry、surprised、blink……可以混合）、`setBaseMorphs`（一直带着的脸部变形，例如小石头 Fcl_EYE_Surprised 0.3 让眼睛大一点；表情里眼睛有动作时自动退掉）、`toBone`。描边材质是背面渲染，three.js 会把 `transformedNormal` 翻过来，外扩方向要自己用 `objectNormal` 算。
  - `rig3d/garment.ts`：换衣服。贴身的衣服 = 身体网格的一片沿法线推出去（`shellGarment`，和身体共用骨骼）；绕一圈的（毛衣下摆、直筒的外套和棉袄、裤腿、领子、袖口、围巾）= 按身体横截面的凸包一圈圈连成的筒（`hullRing` 用三角形和平面求交，axis "x" 时绕平伸的胳膊；`spanRing` 取一段里最粗的；`envelope` 往下只张不收；`folds` 衣褶），`bandGarment` 每个点照抄最近的身体顶点的蒙皮，`skirtBelow` 以下改成裙摆的蒙皮，`open` 做前面敞开的外套和翻领；硬的零件（靴子、砖、铁鞋底、铃铛、圆珠笔）用 `rigidPart` 挂在骨头上。花纹、绗线、口袋、纽扣、袖标的字都在着色器里按静止姿势的坐标 `rp` 和法线 `rn` 画（字用 canvas 贴图 `textures`，片段里叫 uT0）。
  - `rig3d/hairchain.ts`：模型自己的头发骨头一节一节按世界方向摆（收拢扎起、垂下来、失重往上飘）。`rig3d/parts.ts`：每帧按重力、失重、风重算形状的管子（围巾的两头）。
  - `cast3d/chengtuo.ts`、`cast3d/xiaoshitou.ts`：两个人；`cast3d/boots.ts`：铁靴（按脚踝为原点做好，能从秤砣脚上拿下来套到小石头脚上）。每个人 `update(t, { float, wind })` 每帧调用，`footLift` 是站在地上时根节点要抬高多少；小石头 `setWear({ coat })` 穿上或脱下妈妈的外套。
- 设定页 `sheets/人物三维.ts`（样片 22 秒：0–8 秒两个人转一圈，8–12 秒秤砣的表情，12–16 秒小石头的表情，16–22 秒小石头穿上妈妈的外套再转一圈），`scenes/people.ts` 把它放在时间轴上给用户审核，正片开工时换掉。单人测试：`sheets/三维测试.ts`（秤砣三视图和头部特写）、`sheets/男孩测试.ts`（小石头，t=1 穿外套）。
- 用户 2026-10-16 认可了这两个人物（「可以了，模型就这样」），作废的 2D 人物代码已删。

## 秤砣（19 岁，扫天的）
- 剪影：小小的人 + 一双大得不像话的铁靴（硬铁，靴口一圈铆钉，两道麻绳箍，锈斑，厚黑靴底，靴口露出三块写着「活下去」的砖）——一眼看出「沉」。
- 藏青帆布工作外套：敞着怀，宽宽大大到大腿一半，袖子挽到小臂（挽起的厚袖口），胯两边两个大贴袋，翻领；左胸口袋插着那支两块五的圆珠笔（白笔杆、蓝笔帽）；左臂一圈红袖标，黄字「扫天」。
- 里面米白粗针毛衣（竖罗纹，衣襟开口、挽起的袖子下面、毛衣下摆露出来），芥末黄粗毛线长围巾绕脖子一圈、两头垂在胸前（一长一短，末端有穗子）；炭灰工装裤塞进铁靴；深褐色眼睛。
- 黑色长直发、齐刘海，两缕长鬓发垂在脸旁；后面的长发在肩胛骨的位置用锈红色的绳松松地扎住（妈妈的颜色）。长发是为了夜里飘起来、最后在白的边上发亮化成灰时好看。
- 「轻」靠长发、鬓发和围巾的两头：失重时往上飘，眼泪往上飘。还没做：夜里赤脚和脚踝上的红绳（脱掉铁靴的样子）。

## 小石头（7 岁，男孩）
- 底模 HairSample_Male（成年男性）缩成小孩：整个人 0.62、头 1.42、脖子 1.08、腿 0.75、肩膀 0.86（胳膊放回原来大小）；身高约秤砣的 0.65，约 3.6 头身。脸：眼睛以下收短 0.88、下巴两边放宽一点、眼睛常带 Fcl_EYE_Surprised 0.3、眼线改成深褐；刘海正中那一缕缩到 0.6（露出眼睛）。黑色碎发，头顶一撮呆毛。
- 「妈妈手缝的」：豆绿小棉袄（直筒、鼓鼓的，横着一道道绗线，立领，一排米白布扣，右胳膊肘一块橘色补丁——用妈妈那件外套的布）、棕色灯芯绒长裤（宽松直筒，左膝打补丁，裤脚卷起一道）、黑布鞋钉着铁鞋底（城里人人穿铁底鞋）；右脚踝一根红绳拴着小铜铃（听得见铃声，孩子就还在地上）。
- 44 秒以后一直穿妈妈那件橘色大外套（`setWear({ coat: true })`）：大到拖到小腿、袖子盖住手、大翻领、三颗大扣子，下摆一圈缝着铅块（一块块鼓起来，中间有缝线）。96 秒他把外套脱下来摊在地上。
