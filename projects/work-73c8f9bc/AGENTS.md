# stalk ur socials

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 需求
- 用户要求：抖音会火的剧情 MV，看完让人感动、震撼或能回味。
- 剧情提案只给一句话（每个备选一句），用户确认剧情后再做分镜。
- 流程（用户定的）：分镜表 → 视频草稿（定场景、转场时间点、运镜）→ 用户审核草稿 → 精细化成成片。

## 剧情（用户 2026-10-13 选定）
《屏蔽》：一个没有头像的陌生号三年来在她每条动态下面留言，「这么晚还不睡？」「那个男生配不上你」；她吓得拉黑，对方又换个号缠上来，查到最后才发现，那是被她屏蔽了朋友圈的爸爸。
- 分镜表在 `分镜表.md`（22 个镜头，46.6 秒）。
- 开头（用户定的）：点「发布」之后评论区马上出现陌生号的评论，通知也弹下来，然后镜头移到评论区那条评论 → 她打开消息列表，一划全是这个陌生号的评论 → 表情特写。发动态到收到评论在 2 秒内，表情特写 5 秒内放完。现在是 0.2 秒按「发布」、陌生号的新评论一条接一条地来，但只留三条（用户：消息别太多，要像骚扰、不像关心）：0.73 一发出就来「这么晚还不睡？」，1.45 镜头推到第一条时来「窗户关好」，7.28 拉黑前来「还在看手机？」（「怎么不回我」用户觉得太骚扰）；消息列表里的旧评论也改成偏骚扰的（和谁出去了、那个男生是谁、裙子太短、瘦了），回看才读得出是爸爸（每条都有顶部通知 + 红色计数 + 震动）、1.93 秒进消息列表、一甩到底（用户要快），2.71 秒就刹在「瘦了🌹」（2023-06-18）上、镜头推近，3.86–4.83 秒表情特写。
- 15 秒的大转场（用户定的「镜头穿越很远很远的地方，到达另一个手机屏幕」）：15.15 歌声停顿时从她的脸拉出窗户 → 15.42 甩上夜空 → 15.56–16.4 飞越城市灯海、高速、田野远山 → 冲进远处那盏暖灯 → 16.7 落在他的手机上（代码 acts/journey.ts）。「同一时刻」卡片在落地后出现。
- 28 秒（用户定的）：爸爸上划解锁 → 她的微信资料页，朋友圈一栏什么都没有 → 点开朋友圈，一条横线出现在 29.87 的高音上（桥段假声「happy」的尾音，约 F5）。
- 草稿已通过（用户 2026-10-13：「草稿完美」）：场景、时间点、运镜、转场、歌词和关键音效都定了，不再改结构。
- 精细化已做完（2026-10-13，等用户审核）：爸爸重画（花白鬓角、老花镜、保安帽、深蓝制服外披军大衣，圆手）、锁屏壁纸（年轻的他扛着小时候的她）、岗亭（背面、正面、桌面俯拍、雪夜外景、厂门口）、她的特写和卧室（台灯 → 月光）、枕头俯拍、被窝、飞越转场（老楼外墙、月亮、雪原、雪山）、宿舍回忆；人物都按场景的光重新打光。时间点、运镜和音效没动。

## 制作说明
- 代码在 `acts/`（不用 `scenes/`：这个作品以前出现过 scenes/ 文件夹在预览里失效的情况）：timeline.ts（音乐剪辑、镜头起点的拍号、唱词时刻）、ui.ts（手机界面）、world.ts（她的房间、她的特写、枕头俯拍、被窝、宿舍）、journey.ts（15 秒飞越）、shots.ts（手机、取景、甩镜）、act1–3.ts、lyrics.ts。
- 爸爸、门卫室和雪已经放进素材库 s0rrow 的 `code/blocked/`（2026-10-13，用户要求）：`drawDad`（blocked/dad.ts）、`gateNight` / `boothBack` / `boothFront` / `deskTop` / `boothOutside`（blocked/booth.ts，厂名、便条、挂钟等是参数，默认就是本片的）、`snow`（blocked/snow.ts）；人物打光 `litFigure` 在 draw.ts。作品直接导入，要改就改素材库再 `materials_use` 加 `update: true`，不要拷回作品。
- 打光：人物用 `litFigure`（先整体压暗 shade，再叠点光，最后一圈轮廓光）。点光用 screen 叠加会把墨线冲灰，范围要小、强度低（手机光 r≈430、a≈0.4）；夜里的屏幕光用 lighter 叠在暗的布料上才看得出。
- 音乐：歌曲 0–15.20 → 30.61034–46.23 → 61.64034–结尾（audio.json 三个片段），`songTime` 把作品时间换回歌曲时间。
- 陌生号的每条留言后面都带一朵画的玫瑰（中老年人的表情习惯），回看能认出是爸爸；爸爸的手机字号最大、贴膜裂了。
