# [v2.3]反乌托邦 - 乌托邦P

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 这是什么
- 《[v2草稿定稿]反乌托邦 - 乌托邦P》（作品 `3d80f743`）的成品：把草稿做成高质量的 2D 动画成品。**这次是推倒重做**（用户 2026-10-17）。
- 草稿 AGENTS.md 里草稿阶段的约定全部作废（精细化不改剧情/运镜/切点、不使用任何现有素材库等）。经验库里「精细化时不改已通过的运镜」是通用偏好，这次是本片特例，**不要改经验库里的那条**。
- 草稿只读参考：用 work_read / search（scope works）读 `3d80f743` 的 `故事.md`、`project.ts`、`audio.json`、`AGENTS.md`（用户逐段定过的剧情）和 `yinli/` 代码。

## 一、不变的骨架
- 整首歌 152 秒，不剪歌；故事《引力》的世界观、核心人物关系、结局和主题不变。
- 时间以草稿为准：草稿 `故事.md` 的剧情表、`project.ts` 的镜头标记、`audio.json` 的音效时间。
- 草稿代码可以读来查数值，但不沿用写法，全部按剧情需要重写。

## 二、可以大胆改的
- 场景、动作、运镜、人物、配色、分镜都按剧情重新设计；有更通顺、情绪更高、画面更美的表达就改（用户：「我相信你的审美和判断！」）。
- 小改动直接做，在总结里说明改了什么；**动到剧情走向、结局、增删人物先问用户**。
- 运镜用情绪运镜：每个镜头先写下情绪和它卡的歌词，再设计镜头。每个镜头都要推进剧情、带出情绪或制造震撼，不放无意义的空镜。
- 音效跟着新动作重新对时间，可以增删。

## 三、画面和角色
- 2D。配色按音乐的感觉设计，符合国内大众审美，不压抑（不用灰黑、重暗角）。
- 角色用剪纸动画 / 二维骨骼动画，不必照搬文档设定：每人有自己的轮廓、配色和动作习惯，按剧情需要做出特色。
- 主要角色按需要做转面（正面、3/4 侧），不做真侧面，需要时用其他方式绕过。
- 动作要有预备、跟随与重叠、缓入缓出和弧线运动；站着时有呼吸和眨眼。
- 框架和库自己选（Canvas / Pixi / Three / gsap 等，可以组合），但必须按绝对时间渲染、任意跳转画面一致，随机用固定种子，渲染速度要撑得住导出。
- 可以新建素材库放可复用的角色、骨骼和镜头代码，可以关联需要的经验库（用户已同意）。

## 四、横屏口子
- 先做竖屏 1080×1920。
- 所有排版按 `options.width` / `options.height` 计算，每个镜头按「要拍到的主体范围」算取景，不写死竖屏坐标，文字位置也按比例。
- 竖屏完成后复制一份改成 1920×1080，再逐镜调整取景。

## 五、流程
1. 先给用户看：2–3 张风格关键帧、主要角色设定图（含转面）、一段 5–10 秒的动作样片（放在 `sheets/`）。用户确认后再铺开全片。
2. 在作品里维护「成品分镜表」（`成品分镜表.md`）：每镜的时间、歌词、情绪、镜头设计、和草稿相比改了什么、完成状态，每做完一镜就更新。
3. 一个镜头一个镜头做：做完用 preview_frames 看画面、preview_motion 查运动，没问题再做下一个；每做完一幕停下来让用户看。
