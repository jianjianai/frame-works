# i have no friends（重置版）

在这里记录这个作品自己的需求、风格约定和制作说明（AI 每次进入作品都会读取）。

## 这是什么
- 从首发版 work-bdd5c2f8 复制（恢复到它发布前的版本 91339a9，所以可以编辑；作品内部名称仍是 work-bdd5c2f8，素材地址照旧写 `films/work-bdd5c2f8/...`），按首发复盘和《unhappy》积累的经验重置。复盘依据在经验库「剧情音乐短片」；`public/uploads/` 是首发版的后台数据，不是这一版的。
- 目标：99 秒 → 56.6 秒；反转从 67 秒提前到 33.7 秒（首发版在 34 秒时还有约 13% 的人，67 秒只剩 5.7%）；删掉重复已知信息的情绪蒙太奇；拍出他躲起来的状态（回忆里不拍他开飞行模式，见下）；兑现后 6 秒内收尾并加点赞、评论引导。
- 发布后：和首发版对比（同一个故事，99 秒 vs 57 秒），数据写进经验库「剧情音乐短片」。

## 重新设计（进行中，用户已确认分镜）
- 用户要求「剧情主体不变，分镜、动画、场景、彩蛋全部重新设计」。分四段做，每段做完给用户看分镜再往下：① 第一遍副歌 0–17（**已完成**）② 第三遍副歌 17–33.7（**已完成**：act4.ts 文件头有时间表；蛋糕店橱窗从店里往外拍、焦点从蛋糕拉到他脸上，大蛋糕是 sets.ts 的 `bigCake`，派对上要用同一个并加 `candle17`；红色 ❗ 画在灰调外）③ 反转 33.7–50.4（**已完成**：act5.ts 文件头有时间表；关飞行模式时从开关扩散的彩色圆环；99+ 里三个一拍长的插入镜头 INSERTS；X 脸每拍掉一个；派对上小雨捧着插了金色 17 的大蛋糕，阿杰糊脸用的是同一个蛋糕的一块）④ 尾声 50.4–56.6（**已完成**：他双手捧着手机，身后是虚化的派对；班群里状态栏没有 ✈ 了，单手打「谢谢你们。」发送成功 ✓，屏幕上沾着奶油，回复卡拍；点赞和评论引导仍在 lyrics.ts）。四段都已做完，各段的时间表在 act1/act4/act5/act6 的文件头；下面「剧情（作品时间）」一节是重新设计前的版本，细节以文件头为准。
- 总设计：飞行模式 = 他给自己的世界调了灰。反转前用 `grade(ctx, GREY=0.38, …)` 把画面去饱和，只有烛光（`birthdayDesk` 的 layer "scene"/"flame" 分开画）、红色 ❗ 和反转时控制中心里的橙色开关是暖的；回忆用 `oldFilm`：**不改变画面颜色**（用户要求，原来的棕褐色已去掉），只叠胶片相机效果：18fps 画面抖动（±1.25px，用户说抖动减弱；转场里的抖动也减到±3.5/±1.5px）、粗颗粒（overlay 中灰噪点）、深灰灰尘/毛发/划痕（不用白点）、曝光闪烁、中性暗角；用户说「get 不到主角在回忆」→ 不要加镜头（加过「闭眼、头顶开出回忆窗」的镜头和发光边框，已撤掉），强暗角也试过、用户说影响观感（已改回轻暗角）→ 倒带试过也不要了 → 现在用「老式屏幕竖线转场」（act1 `shotOldScreen`）：8.09–8.61 两拍，现在的画面（他在黑屏里的倒影）起抖动、冒出一层层闪烁的黑白竖线，中间白闪一下时画面跳到上午的走廊，竖线再慢慢变稀，不配音效；回忆播放中 `oldFilm` 也随机出现同样的竖线（两条时有时无、慢慢漂移的，每帧跳动的 1–3 条，平均约 1 秒一次的短促密集爆发；amount 0.45 的第三段闪回更淡；转场和回忆里的竖线都用 draw.ts 的 `linesOutsideCentre`：竖线本身在整个宽度上随机分布，再用以屏幕中心为圆心的径向遮罩（半径 0.3W 内几乎看不见，到 0.78W 全显），所以中心一圈不明显、越往外越明显（上下和四角最明显）——用户要的是「中心区域圆圈」，不是按每条竖线离中心的左右距离）；之前的倒影推进为 6.79–8.09。第三段的三个闪回是「他们那一边」，不加这个边框；37.31 关掉飞行模式时颜色从屏幕扩散开、X 脸掉落（待做）。转场尽量一镜到底；人物用 `blinkEyes` 眨眼。
- 第一段分镜（act1.ts 文件头有时间表）：0 烛火特写拉开（窗外楼下已有手电光和粉色横幅，彩蛋）→ 2.35 锁屏点亮、下拉刷新 → 4.44 班群（最后一条 10:12）→ 6.79 息屏，推进黑屏里他的倒影，眼睛里亮起光 → 8.61 走廊（他们藏起横幅，金色「17」气球飘在头顶）→ 10.70 拉起帽子、慢推到 12.79 → 12.79 教室爆笑（阿杰手机壳上有粉色奶油）→ 14.87 笑声逼近 → 哈。
- 后面三段的分镜见对话里确认的方案：17.1 蛋糕店橱窗（他看着的大蛋糕 = 最后糊到他脸上的那个）→ 路灯下拎着小盒子走 → 发送失败 → 删除 → 同构图点蜡烛许愿吹灭；33.7 控制中心橙色 ✈ → 37.31 关掉、颜色扩散 → 99+ 里三条消息各闪回一个「他们那一边的今天」→ 从夜空摇下的窗外 → 冲出单元门、蛋糕糊脸 → 尾声。

## 剪法与时间（作品时间 ≠ 歌曲时间）
- 115 BPM，第一拍 0.265（歌曲时间），`beatAt(k)`。歌曲：第一遍副歌 0–16.96、第二遍 16.96–33.39、桥段（秋千）33.39–50.35、第三遍 50.35–67.05、第四遍 67.05–83.74、尾奏到 99.1。
- 画面：0–16.96 第一幕（作品时间 = 歌曲时间）→ 16.96 起直接接第三遍副歌的画面（第四幕）→ 第五幕反转 → 尾声。第二幕、第三幕整段删掉（scene.ts 已去掉，原文件在 bdd5c2f8 和素材库 reference/）。
- act4 / act5 / act6 的代码仍按**歌曲时间**画（`designScene` 的 t0 没改），只是图层往前挪了 JUMP = 16 小节 = 33.3913 秒：作品时间 = 歌曲时间 − 33.39。改这三幕时，播放器里的 x 秒 = 代码里的 x + 33.39。
- 音乐（audio.json）：0–21.13 按原曲放（第一遍副歌 + 第二遍副歌第一句，因为两遍副歌开头一样，画面在 16.96 就切到回家了）；21.10 在两边都是人声空隙的位置（"alone" 和 "I feel" 之间、下一小节起拍前）跳 16 小节接第三遍副歌，交叉淡化 0.06 秒。没有在小节线 16.96 直接跳，是因为那里两边都还拖着人声尾音（"face" / "me"）。
- 歌词（lyrics.ts）跟着实际播放的音频走：21.10 前用歌曲时间 = 作品时间、画第 0–4 句；之后歌曲时间 = 作品时间 + 33.39、画第 13–19 句。
- 闷音（吹灭蜡烛）：低通 1500Hz、q 0.5（原来 480Hz；《unhappy》用户说 520Hz「影响听感」），吹的时候 0.3 秒交叉淡入，灭了以后全闷，反转的重拍上 0.03 秒切回干声。
- 卡点：新加和挪过的动作、音效都在八分音符网格上——23.22 发送、24.00 ❗、26.87 切到书桌、27.92 划火柴、37.31 关飞行模式、51.40 发送成功、三条回复各占一拍、53.48 / 53.61 双击点赞（十六分音符）。其余镜头切换原本就在拍点上。

## 剧情（作品时间）
1. 0–8.6 冷开场：23:58 戴派对帽对着纸杯蛋糕，钩子「今天是我17岁生日 / 手机 0 条新消息」；锁屏 0 条新消息（状态栏右上角 ✈，彩蛋）。
2. 8.6–12.8 闪回「今天上午 10:12」：走廊里同学把横幅和礼物藏到身后 → 唱到 hide away 他拉起帽子，慢推到 12.79。**回忆里不出现他开飞行模式**（用户：他要是记得自己开了飞行模式，就不会忘记自己开了）；线索只有状态栏的 ✈。微信里也不显示「当前网络不可用」（用户要求去掉）。
3. 12.8–17 被嘲笑（惊喜策划群（不含寿星）彩蛋）→「哈」。
4. 17.1–33.7 第三遍副歌：21:52 低头看着班群走回家（手里加了亮着的手机，让这个镜头有事）→ 班群打「其实…今天是我生日」→ ❗ 发送失败 → 删掉 → 23:58 自己点蜡烛、许愿「希望…有人记得我」、吹灭（音乐变闷）。
5. 33.7 反转：黑暗里拿手机当手电筒 → 控制中心里飞行模式是橙色的 →「!?」→ 37.31 关掉 → 99+ 条消息（小雨那条改成「上课大家是在笑阿杰差点说漏嘴…不是笑你啦」，解释闪回里的笑；原来那条说秋千，秋千段已删）→ 窗外同学举着横幅，X 脸消失 → 下楼被糊一脸蛋糕。第四遍副歌中文歌词被红笔划掉改写。
6. 50.35–56.61 尾声（6 秒）：同一个班群发「谢谢你们。」——发送成功 ✓（和 ❗ 首尾呼应），三条回复（阿杰「生日快乐！！！」、班长「下次再开飞行模式试试？」、小雨「横幅上的字是我写的！」）；53.48 起手机退后，叠点赞和评论引导直到最后一帧：双击爱心 +「点赞的人，生日那天消息 99+」；评论卡「回看：第几秒就能看出他开着飞行模式？」+「答案打在评论区 ↓」（答案：第 2–3 秒锁屏状态栏右上角的 ✈，只要打一个数字，也把人带回开头重看；原来问「他在第几秒开的飞行模式」，回忆里删了开飞行模式后改掉）。删掉了秋千分耳机、手写金句、「去给朋友发条消息」和 P.S. 卡。

彩蛋（别删）：状态栏右上角的 ✈；开头窗外楼下的手电光和粉色横幅；走廊里藏起来的横幅和「17」气球；惊喜策划群（不含寿星）和手机壳上的奶油；蛋糕店橱窗里的大蛋糕。

## 风格约定（沿用首发版）
- 手绘涂鸦风，参照封面：黑色抖动描边（每秒 8 帧 line boil）、平涂色、胶片颗粒（grain 图层 overlay）。其他人在反转前都是封面里的蓝白「X」脸，反转后露出笑脸。
- 白色划痕：首发版有评论说「头皮屑怎么那么多」→ 头发上不再画，卫衣和裤子上调淡、减少（kid.ts 的 specks）。
- 手机操作镜头：双手从卫衣袖口伸出握着手机，用拇指点按；飞行模式用左手拇指按。手掌和拇指是同一个轮廓，用户确认过，不要改回单根食指（代码在 `scenes/lib/hand.ts`）。
- 歌词：英文逐词卡拉 OK（酷狗 KRC），中文按词一一对应（`lyrics-data.ts`，改歌词必须保持词数一致）；歌词不随节拍跳动，只有正在唱的词轻微放大；中文 64px。
- 安全区：顶部 y<180 留给抖音顶栏；标题胶囊 y≈214（「17岁生日 · 0 → 99+ 条新消息」，37.8 秒翻成 99+，尾声前淡出）；歌词块以 y≈1335 为中心。

## 精致化（建模 / 场景 / 运镜）
- 建模：`kid.ts`、`people.ts` 换成素材库 s0rrow 的精细版（《unhappy》里用户确认过的那套：结构化的蓬发和发丝、带虹膜高光的眼睛、眉毛、IK 关节手臂和真的手、衣服明暗）。唯一改动：耳机默认戴着（这个角色在封面和首发版里一直戴耳机，传 `earbuds: false` 才摘）。`draw.ts` 加了精细版需要的 `tubePts`/`ik2`/`shaded`/`lerp2`/`rotPt` 和 `filtered`。hand.ts 没换（用户确认过这一版的手）。
- 场景（`sets.ts`，函数名和参数不变）：卧室加了书架和绿植、墙上的日历（今天圈了红圈，小彩蛋）、窗帘、月亮和窗外的万家灯火、落进屋里的月光；书桌有木纹、一摞课本和笔筒；走廊有日光灯、窗外的树、挂「高二(3)班」牌子的教室门、透视地砖和窗光里的灰尘；教室有黑板上的粉笔字和 F = ma、粉笔槽、挂钟、后排课桌、斜射的阳光；回家的街分四层视差（星空月亮、远处楼群、带窗帘和空调的居民楼、路灯和电线、人行道和马路）；窗外那场（`streetBelow`）是对面的楼（亮着的窗里有邻居在看）、红白条纹遮阳棚的小店、马路和他家楼下的人行道，窗玻璃上有淡淡的反光，窗帘有褶皱；派对（`buildingEntrance`）在他家单元门口：瓷砖墙、他身后透出暖光的门厅（给他一圈轮廓光）、壁灯和门铃面板、顶上一串彩灯，整体虚化 2px；手机近景（锁屏、发送失败、消息轰炸、发送成功）背后加了虚化的光斑 `bokeh`，像身后远处的房间和街灯。
- 运镜：`draw.ts` 的 `handheld(abs, amp, seed)`（几个正弦叠加的慢漂移，没有逐帧抖动）加在每个镜头上，安静的镜头 4–5、紧张的 7–8；推拉用 `easeInOut`；走廊跟拍他走进来、教室被笑时慢推到他脸上、回家路上镜头随脚步轻微起伏、窗外那场从夜空摇下来（约 1.4 秒）；走廊和教室的背景用 `filtered(ctx, "blur(1.4–1.6px)", ...)` 稍微虚掉（景深）；开头甩进手机时加动态模糊（`blur(14·sin(π·whip))`）。同一个画面跨镜头时用同一个 seed，漂移接得上（发送失败→长按删除都是 8）。

## 字体（新加中文时必须看）
- `public/fonts/*.woff2` 是首发版按当时用到的字做的子集。这个环境不能跑 `node production/fetch-fonts.mjs`，新加的字用补充子集：`asset_import` 下载 `https://fonts.googleapis.com/css2?family=<字体>:wght@<字重>&text=<新字的 URL 编码>`（得到一个 CSS）→ 读出里面 fonts.gstatic.com 的地址 → 再 `asset_import` 存成 `public/fonts/<名字>-extra.ttf` → 在 draw.ts 的 `FONT_FILES` 里加一行并写上这些字的 unicode-range。现在有 `zcool-kuaile-extra.ttf`（结尾引导的字）和 `noto-sans-sc-400-extra.ttf`（小雨的通知和回复）。漏了的话画面会退回系统字体，导出时可能变成方框。

## 结构
- `scenes/act1.ts`、`act4.ts`、`act5.ts`、`act6.ts`：四幕；`scenes/lyrics.ts`：钩子、标题胶囊、中英歌词、红笔改写、结尾引导；`scenes/lib/`：draw（笔刷、字体、节拍）、kid（主角）、people（同学、X 脸）、phone（手机界面、控制中心、通知）、sets（场景）、shared（生日书桌，第一幕和第四幕同构图）、hand（握手机的手）。
- `audio.ts`：合成音效（打字、发送、失败、火柴、吹蜡烛、开关、消息轰炸、蛋糕、礼花、回复、轻点）。`audio.json`：歌曲四段（见上），音乐轨对音效轨轻微闪避。

## 待用户确认 / 可以再调
- 21.10 的音频接缝建议戴耳机听一遍；不顺的话前后挪几十毫秒（songA 的 duration、songB 的 start 和 offset 一起挪，offset = start + 33.3913）。

- 回忆里不拍他开飞行模式（用户：他记得就不会忘），反转保持「意外」，线索只有状态栏的 ✈。
