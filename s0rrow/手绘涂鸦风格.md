# 手绘涂鸦风格
画面风格的数值、版式和角色画法（参照歌曲封面），以及精细化建模的做法。

## 线条与上色
- 黑色描边 #17161a：外轮廓 5–6，内部结构 2.2–3.5，圆角线头。所有形状带抖动（0.6–2px），每秒换 8 次（line boil）；同一物体固定 seed。
- 平涂 + 一块阴影（光从左上来，阴影放右侧/下方，用同色系深色，`shaded()` 在形状内裁剪着画）；衣褶、发丝、指缝用同色系深色细线，不用黑线。
- 光效用 `glow`、`lightPool`；最上面叠胶片颗粒 + 暗角。白色划痕只用在背景/衣服上，透明度 ≤0.55。
- **光影**（用户：「光影和美感也是留存率的关键，特别是开头」；做法在 work-afa1129b 的 draw.ts「light and shadow」和 shared.ts `birthdayDesk`，素材库版还没有）：每个夜景先定一个**有来源的主光**（蜡烛/路灯/屏幕），它照到的东西带它的颜色，照不到的落进冷色的暗里（径向压暗 + soft-light 偏蓝），再加一个**来自背后的冷色轮廓光**（月光）；人物身上的光用遮罩只画在人物上（`figureMask` + `onFigure`），近光源一侧暖、远侧暗；轮廓光要画在**墨线内侧**（遮罩错位相减，`rimLight`），画在线外就像贴纸白边，而且要淡（0.3–0.5）、离光源越远越淡，刺头发上太亮会变成一段段白线；点光源在人背后的墙上投出放大的影子，叠在灯光之后、扣掉人物本身（`castShadow`），避开窗玻璃；空气里加柔边光柱和浮尘（`lightShaft`、`motes`）；桌面加光池和朝镜头的竖向倒影，前沿压暗，让下半屏不再是一块平的颜色；特写时背景虚化、拉开后变清楚；最后给整幅夜景加高光辉光（`bloom`，0.2–0.3，不要用在白天的回忆上）。手机镜头的背景画成**失焦的真实环境**（房间里的烛光大光斑和月亮、街上的路灯），手机四周加屏幕冷光、金属边框左暖右冷反光，手机才从暗背景里跳出来；灰调（grade）里的光斑会变成灰色的「灰尘球」，背景光斑要画在 grade 外面、自己选好低饱和的颜色。
- **场景美感**（用户：「把场景做得更有美感」，开头 5 秒）：空墙 + 抽象海报显得单薄，换成有生活感、会发光的陈设——一串暖白串灯夹着拍立得，特写时背景虚化，它们就是人物头后的一串光斑（最「电影感」的第一帧）；窗外加层次（远近星星、飘过月亮的薄云）；窗光投在桌面上成窗格形状；手机壁纸也是画面的一部分（黄昏渐变、月牙、山坡上的秋千剪影）。会发光的陈设要在房间压暗之后再补光晕，并用人物遮罩扣掉被人挡住的部分。新陈设放在标题字下方、关键线索（日历）旁边不压着它。
- 配色：卫衣蓝 #2e6f96、肤色 #f3dcae、头发棕 #7a5a2b、外卖黄 #f3b30c、深夜蓝 #141b33、警示红 #e8343c、蜡烛黄 #ffc65a、纸色 #efe6d2。

## 精细化建模（用户要求“更精细”后的标准）
- 头发（封面的蓬发）：圆顶轮廓上很多小而不规则的锯齿（半径的 3–8%）+ 少数大发团，右侧发绺下垂；刘海是参差的尖；从刘海缺口往上画短发丝线、亮面在左侧几笔高光、整片头发撒深色短划（封面的纹理）。避免：大而均匀的尖刺（像星星/海胆）。
- 眼睛：杏仁形眼白 + 虹膜（深棕+下半圈浅色）+ 瞳孔 + 两个高光；上眼皮粗线、上方一条眼皮褶线、下眼睑细线、眼袋。主角标志是厚重眼皮（sleepy 只睁开 0.3）。
- 脸：刘海在额头投一条锯齿阴影；下颌一侧阴影；眉毛单独画、随表情变角度。
- 手：手掌和拇指是一个轮廓（先粗描边再一起填色），手指分缝用浅棕细线；有 relax/fist/open/hold/flat 几种手型，按前臂方向旋转。
- 手机镜头不画手后，镜头要补上手原来交代的事（i have no friends 重置版全片去掉了手）：手机带侧键（息屏时电源键按进去、手机一晃）和玻璃反光、白色触点；「他想开手电筒」由镜头先去手电筒那格、触点按下、那一格变白、手机后面亮起冷白光来做，再一下甩到橙色 ✈；人拿着手机且面对镜头时画手机背面（`phoneBack`，可开闪光灯），手机压在拳头上就不会露出方向反的拇指。黑屏里的倒影不要画手（捧在胸前却没拿东西），胸口以下淡出、稍微虚。
- 手机近景默认**不画手**：《unhappy》里握手机的手改了五版用户仍觉得怪，最后说「手太难做就不做了，只显示手机」。现在只画手机，拇指按下的地方画半透明白色触点（类似「显示触摸」），打字、删除、发送、滑动仍看得出来。特写里必须露手（握笔、放下牛奶）时，用户要求「用简单的圆就行」：袖子末端一个描边的肤色圆 + 右下一块阴影（act1 的 `roundHand`）。下面是当时的握法笔记，下一支真要画手再参考。
- 双手握手机打字（`hand.heldHands`，用户给卡通参考图定的动作，画法仍是本风格）：手掌在手机**后面**（用 evenodd 裁到手机外），只沿机身两侧露出一圈、在机身下方露出掌根和手腕；拇指粗（约 0.2 个机身宽）、几乎是直的、微微向上拱，从手机下半部两侧斜着伸到键盘中间，圆指尖 + 指甲，关节一条浅棕细线；拇指根沿侧边滑动保持长度不变，打字时手只跟一半（不随按键上下跳）；袖子从画面下方两角伸出画外。避免：手掌画在屏幕前面挡住键盘（像连指手套）、拇指从机身底角伸出像钳子、拇指弯成钩、袖子在画面里截断、白色高光条这类非本风格的上色。
- 四肢：`tubePts` 锥形管 + `ik2` 算肘/膝；袖口罗纹、肘部褶线；帽衫有袋鼠口袋、抽绳和下摆罗纹。
- 狗（豆豆）：奶油色毛、焦糖色背和耳朵、一只眼睛的深棕眼罩、灰白口鼻毛（老）、红项圈+骨头牌、臀部心形斑、一只耳朵缺口；轮廓用小毛簇。正面的垂耳要画在头**前面**挂在两侧（画在后面会被头挡住）；项圈是横跨脖子的弯带；脖子先画、身体后画盖住脖根；尾巴用光滑锥形管+两撮毛（细管上加毛簇像树枝）。
- 女主（林夏）：深棕波波头，刘海用平滑曲线画成浅波浪边（不要男主那种锯齿）、头顶一条带小缺口的月牙形高光、两侧发丝面颊、向日葵发卡；眼睛更大、外眼角两根短睫毛（多了像蜘蛛腿）、没有眼袋；少量雀斑+淡腮红，害羞时腮红加斜线和冒烟。睡衣粉色带小爱心，上学穿奶油色开衫+藏蓝百褶裙。
- 迭代方法：先做临时“设定稿”图层把各姿势排在一页上看，结构对了再进镜头。覆盖在脸前的东西（书、手机）要在 drawKid 之后单独画，`grip` 会被头压在下面。
- 挡脸的道具要画成真东西：课本有书名（「物理」）、色带、书脊阴影和露出的书页，两侧边缘叠上四个指尖，头发和发卡从书顶露出来（`places.textbook`）。一块纯色方块挡住整个头会像面具。
- 姿势坑：`handL/handR` 会覆盖任何 `arms` 预设，只在 custom 时传（不然手会跑到头两侧，像一对耳朵）；坐在桌后的半身用 `arms: "down"`（`table` 看起来像叉腰）；背影也用 down，自定义手腕会把手臂画在背上。路人（people.ts）「手背到身后」从正面看像叉腰（肘部必然往外顶），也不要用 `arms: "behind"`（直接没有手臂）；要表现「藏好了、装没事」用双手垂直立正，藏的东西从身后露一角。work-afa1129b 的 people.ts 加了 `handL/handR/shapeL/shapeR/bendL/bendR` 覆盖单只手臂（素材库版还没有）。
- 正面拿着手机看（走路低头看手机）：我们看到的是**手机背面**（深色机身、左上角摄像头、屏幕的光从顶边漏到他脸上，phone.ts 的 `phoneBack`），拳头握住手机下半截、**大拇指朝上**（用户指出过方向反了）。drawKid 右手前臂从下往左上弯时 `hand` 会把拇指画到下面：右手传 `shapeR: "hidden"`，在 `grip` 里用同样的 `ik2([100,192], 手腕, 142, 134, 1)` 算前臂角度，再 `drawHand(..., "hold", mirror = true)` 自己画，手机中心放在手腕沿前臂 30 处再往上一点。另一只手垂着拎东西（蛋糕盒）也一样反了：左手前臂朝下时拇指被画在外侧，要 `shapeL: "hidden"` + `ik2([-100,192], 手腕, 142, 134, -1)` + `drawHand(..., "hold", mirror = false)`，拇指朝身体里侧；绳子从拳头中间（手腕沿前臂 34）垂下，盒子跟着手摇。规律：只要手里握着东西，就看一眼全尺寸截图里拇指的方向。
- 递东西/举着给人看（递牛奶、亮卡片）：胳膊要「V」——上臂从肩往下往外到肘，前臂再往上到手，手在肩高、伸到身体外侧（`handL: [-285, 190], bendL: 1`）。默认的肘部朝上会画成倒 V，用户说「很不对劲」；把手伸直成一条横线也不对。动作拿不准时让用户给参考图。
- 抱东西：不要用 `grip` 在身前放一块色块、再把两只平手或 hold 手贴在上面（用户说「动作非常奇怪」，像爪子）。抱枕头用 `places.huggedPillow`：下巴搁在枕头上，上臂顺着枕头两侧下来、前臂在前面交叉、圆手；枕头颜色要和床上的枕头、睡衣拉开（浅蓝带小星星）。书后面偷看用和对方视角同一本 `textbook` + `bookFingers`，书顶在眼睛下面、只露眼睛和冒烟；书后的胳膊要几乎垂直（`handL/R` 放低到 y≈440），弯肘会从书两侧挤出来像翅膀。

## 字体与版式（1080×1920）
- 英文歌词 Gochi Hand 58px，宽 ≤820；中文 ZCOOL KuaiLe 64px，超 900px 在均衡的空格处折行；最大的一句 76–84px。红笔 Long Cang；手机界面 Noto Sans SC。
- 歌词块中心 y≈1335，占 y≈1240–1430：**人物的脸、关键道具和线索放在 y≈1230 以上**（`camera` 的 dy 整体上移），歌词压在地面/桌面上。手机屏幕里的线索也算：《unhappy》朋友圈的「5分钟前」在屏幕底部被歌词挡住，用户点名——把手机上移、并在画红圈时推近到那行字（线索的屏幕坐标换算成 phoneCloseup 的 cx/cy/s）。
- 顶部 y<180 空着；标题胶囊 y≈214；时间卡放左上 y≈330，别压住墙上的线索（日历、便利贴）。
- 大字幕压在复杂画面上时，后面垫一条暗色渐变带。
- 黑屏/暗屏的手机要认得出是手机（用户说「通过手机屏幕看的感觉不强」）：镜头别推到手机两侧边出画（≤ 1.45 倍）；`story.phoneBody` 画金属边框高光 + 侧键；玻璃上加斜向反光和台灯的暖色倒影；背景换成和黑色机身不同的暗紫床面带虚化光斑（phoneCloseup 的 `backdrop`）。
- 手机近景：手机放到 1.0 倍（聊天字约 37px，原来 0.68 倍用户说看不清）、中心 y≈910，顶部紧贴标题胶囊下方；聊天字号用放大版（37px）；钩子镜头把手机放在钩子字下方、键盘弹起，让最新气泡在 y≈1000、标题栏露在钩子字下面。连续好几个手机镜头时换景别（裁到照片铺满、推近标题栏、插人脸），别一直是同一个全景手机。

## 角色
- 主角：蓬乱棕发、困倦厚眼皮+眼袋、蓝色帽衫（打工时黄色外卖服+头盔）。
- 路人：同一套精细画法；反转前可用蓝白 X 脸（`x`），反转后淡出露出脸。

## 镜头
- 镜头切换在拍点上，而且要切在**乐句的结尾**（对照 krc 的歌词时间）：《unhappy》在小节线 20.52 切走倒影，可「ugly」20.58 才唱，用户说「没和音乐节奏对齐」→ 改到唱完 ugly 的拍点 21.54 切；下一个镜头在回声「Love me」23.96 切入。别在关键词刚要唱时切走对应的画面，也别切在半句里；对应画面要等关键词唱完再转场（她的头像留到「pretty」唱完 19.33，溶变卡在下一拍 19.5）。画面物件可以随拍轻动，歌词不动。
- 不要拍全景把人物缩小：《unhappy》教室第一版从黑板往后拍，人物挤在上半部、下半是空地板，用户说「观感差」。重拍成：从他的座位越肩看她（前景是他的桌面：笔记本、她发卡的小涂鸦、草莓牛奶、握笔的手）→ 她转身对视 → 课本举起 → 反打他的脸 → 放学中景（人物大、下缘裁在桌子）→ 空桌上的牛奶特写。人物脸宽至少 220px。
- 背景用 `filtered(ctx, "blur(2–4px)", …)` 虚化，前景人物更突出；景只画一次，用 `camera` 放大当近景背景，人物在屏幕坐标里画。
- 情绪要配镜头语言（用户要求体现「期待、惊讶、悲伤、自我怀疑」，做法见 reference/unhappy-chat/act1.ts 的 hookCamera）：期待 = 「对方正在输入」出现时镜头屏息往前凑、消失时退回；意外 = 消息弹出时急推（backOut 0.16 秒）+ 震动 + 两圈脉冲；惊讶→失落 = 切到脸先急推一震、表情 wide/up/o，再眼神落回手机（open/worried/flat），最后 sad/sad/frown + 低头 + 慢推大特写 + 荷兰角 + 光变冷；自卑 = 对比的匹配溶变（她的头像熄屏时，他的黑屏倒影浮在她脸的同一位置，同一构图）→ 唱到 ugly 时慢推 + 反光扫过他的脸 + 四周压暗 → 他不敢看自己：低头向下看（look [0, 0.9] + headY、frown），用户说向下看比向旁边看更好；自我怀疑靠表情和内容（长消息→「嗯」「哦」）表达；手机屏幕不要变色（回忆暖色滤镜用户要求去掉），读屏时也不要倾斜/后拉/暗角。急推后检查内容别和画面上方的大字叠在一起。但**要观众读屏幕内容时镜头必须稳**：翻聊天记录用户说「减少镜头晃动，让观众看清消息」——去掉倾斜/后拉/暗角，`phoneCloseup` 传 `steady: true`（关掉手持微晃），翻旧聊天的手势按用户定的：先往上翻到以前（0.6 秒）→ 停住让人看清（约 0.75 秒）→ 一下快速划到底（0.3 秒，先快后稳的惯性）→ 再做下一个动作（点头像）。
- **回忆（闪回）一律用「老式屏幕竖线」效果**，全片、以后每支都一样（用户在 i have no friends 重置版 work-afa1129b 定的，取代《unhappy》用过的泛黄胶片）：
  - **不改画面颜色**：不加 sepia、去色、暖色滤镜（用户：「回忆的效果改成不改变画面颜色，只叠加胶片相机效果」）。
  - **只叠胶片相机效果**：按 18fps 的轻微画面抖动（±1.25px；±3px 用户说要减弱）、粗颗粒（中灰噪点用 overlay 叠，不偏色）、深灰灰尘和偶尔一根毛发（不用白点，白点在手机上像头皮屑）、轻微曝光闪烁、很轻的中性暗角（四角约 0.38）。
  - **随机竖线**：两条时有时无、慢慢漂移的细线 + 每帧跳动的 1–3 条 + 约每秒一次十来条的短爆发；深灰或米白、1–6px 宽。竖线套一个以屏幕中心为圆心的**圆形遮罩**：半径 0.3W 以内几乎看不见、到 0.78W 全显，上下两端和四角最明显（用户：「是中心区域圆圈来，不是按照竖线来」——不要按每条线离中心的左右距离淡化，也不要把线挤到两边）。
  - **进回忆的转场**：两拍左右（≈0.5 秒）的「老式屏幕竖线转场」——当前画面轻微抖动（±3.5/±1.5px），竖线一层层变密、白光闪几下，过半时换成回忆画面，竖线再变稀；用同一个圆形遮罩；不配音效，整个画面不做淡入淡出。转场前可以先慢慢推近一个东西（i have no friends：推向黑屏里他的倒影）。回忆结束直接切走。
  - **转场中间用匹配剪辑换进回忆**（用户说「这次改得非常不错」）：转场前推近的是他的脸（黑屏倒影），竖线下面用约 0.14 秒溶变成**同一位置、同样大小**、有颜色的他（上午的他），再从这张脸一镜到底拉开成回忆的场景。同一张脸从灰变彩，观众一下就懂「这是他在想」，不用加镜头。起点要精确对上：用和上一镜相同的 camera/phone/drawKid 算出倒影脸在屏幕上的位置、大小和旋转（act1 的 `reflectionAt`），回忆的镜头从这里出发。
  - **试过被否的**（别再做）：额外加一个「闭眼、头顶打开回忆窗、钻进去」的镜头（用户：不用加一个镜头）；回忆四周的发光圆角边框；强暗角（四角近乎全黑，「影响了视频的观感」）；倒带转场（◀◀ + 飞快倒转的时钟 + 一天倒着闪过的画面——用户先说不错、要更短，最后还是不要）；倒带音效；泛黄 sepia。
  - 回忆里「他看见了什么」用一镜到底的两层景深讲（i have no friends 走廊 8.35–10.70，替掉了原来他小小地站在左边、同学挤在右边、下半屏空地板的全景）：前景左边是他（大、脚出画，脸宽约 340px），中景右边是同学（脚在地面线上）；对焦来回切——拉开时焦点在他 → 同学进画后切到他们（他虚化 4.5px）→ 他垂眼时切回他（act1 的 `focus`，每层用自己的 filtered key）。「藏东西」要先让观众看清他们在做什么（举着横幅、捧着系气球的礼物），被发现那一下做成漫画节拍：头顶依次冒「!」+ 跳一下 → 半拍内卷起横幅、速度线 → 立正站好，藏的东西从身后露一角，一个僵硬挥手、一个冒汗（正好对上 Everyone is so fake）。最后镜头带视差（墙动 1/4、人动 3/5，墙的左边缘就不会进画）摇到他正中，脸和下一个镜头（拉帽子）一样大，切过去几乎无缝。
  - **反转时重放回忆**（i have no friends 99+ 段，用户说原来的「全部都很烂」：小手机上看不清的通知 + 三个一拍长、另画的插入镜头）：每段给两拍。手机铺满画面、通知每 0.12 秒砸一条，镜头冲进关键那条，它变成下一镜顶上同样大小、同样位置的横幅通知；下面**直接重放前面回忆的同一组画面**（act1 导出 replayCorridor/replaySlip，稍慢放），卡拍时 X 脸掉下来（一团光）露出笑脸——观众认得是同一个画面，反转才有力。不要另画一版「他们那一边」。
- **「他们一直都在」的揭晓**（用户：「改的非常完美」）：三个镜头卡拍——越过他的肩膀推向窗户（他在左下、镜头经过他时他滑出画面，手电光从楼下爬上玻璃和天花板）→ 他的视角垂直往下看：所有人仰头、横幅展开、手机手电筒对着他、前面捧着蜡烛点着的蛋糕，X 脸每半拍掉一个，人和蛋糕都在歌词上方、歌词压在人行道上，人行道下方用粉笔字填满（不留黑底）→ 从楼下仰拍他的窗户：先哭、再第一次笑、点头、跑开去下楼，前景是他们虚化的后脑勺和举起的手机。原来「一个小窗框里挤一群人、4 秒不动」被说「太烂」。
- 别人视角的闪回（i have no friends 反转里「同学那一边的今天」）用同一套效果、强度减半（amount 0.45），不加转场。

  - 更早的版本（只作记录）：《unhappy》里他的教室回忆用过「淡成暖白 + 旧照片色调 + 柔光边」，她的回忆用过「倒带闪烁 ◀◀ + 倒带音效」，用户要求两处统一，当时统一成泛黄老胶卷（`story.oldFilm`，sepia），已被上面取代。
- 剧情关键的消息要「点进去看」，不要只弹一下通知：《unhappy》小美「回个嗯就行」是她删字的原因，用户要求「她点进去看完之后回来把消息都删掉了，回复一个嗯字」。做法：通知弹下 → 触点点它 → 对方的聊天从右边滑进（底下的聊天左移 30% 变暗）→ 镜头推近、荧光笔划出关键句 → 点 ‹ 滑回去，草稿还在 → 删。对话少时让消息从顶部排（chatScreen2 的 scroll 负值），这样推近了标题栏的名字也还在画面里；配角要有自己的头像（`avatar` 的 "mei"）。为它腾时间可以删后面不关键的镜头（这里删了「他在笑」和「抱枕头后悔」）。
- 一段来回的聊天就在一个手机镜头里拍完（用户：「手机这段不要切镜头了，一直收和发就行」）：发送和收到都在同一台手机上发生，对方在打字用标题栏的「对方正在输入...」交代，不切到对方的手机；键盘一直开着（收起键盘会让整个对话跳一下），镜头每收发一条推一下、最后沉到最新的消息上。
- 手机里的内容接内容不要硬切：用 App 里的动作过渡（点头像 → 新页面从右边滑入、旧页左移 30% 并变暗），同一个手机镜头里完成（reference/unhappy-chat/act1.ts 的 shotHistory）。
- 主角没注意到、观众要注意到的线索（戏剧反讽）：镜头和聚光停在主角盯着的东西上（她的「嗯」，径向压暗四周、慢推；用户说变暗效果很好但太浅 → 整个镜头里逐渐加深到 0.95、光圈收窄，最后只剩那个字亮着），线索在画面边缘出现时用全片统一的黄色脉冲圈 + 淡光标出来（「对方正在输入...」），但镜头不移过去。线索文字要和旁边的字一样大，别被顶部胶囊压住。一个手机镜头拍满 3 秒用户说「有点无聊」；拆成四个 0.5–1 秒的镜头又「切换太快，来不及看完」。用户最后定的是「先流泪，再聚焦到嗯字」，而且「相机穿过他的眼睛，之后到手机，之后聚焦嗯字」：他流泪的脸，镜头推到眼睛 → 钻进瞳孔：瞳孔里的反光画的就是下一个手机镜头的整个画面（9:16，同一时刻），放大到正好铺满画面时换成直接画手机镜头（和穿过窗户同一招：反光的圆角和冷色、脸上的光带到接缝时都已变成 0）→ 手机：聚光在「嗯」上，「嗯」随拍发冷光、放出白色细圈（和线索的黄圈区分开），线索在顶部闪两次 → 镜头钻进「嗯」直到它占满画面、四周全黑（聚光半径跟着放大倍数一起变，不然放大后旁边的气泡会露出来）。各约 1 秒 / 2 秒。经验：每个镜头至少约 1 秒、最好 1.5 秒；想要变化就在一个镜头里用运镜（推拉、压暗），不要靠多切。
- 剧情关键信息不能一闪而过：《unhappy》她发出「嗯」后 0.05 秒就切走，用户要求「停留一会，让观众理解打了很多、最后删掉发了个嗯」。做法：停约 0.9 秒，镜头推近那个气泡并移向画面中间、两圈黄色脉冲（和钩子里收到「嗯」一样）、红笔写「删掉了 37 个字」加箭头；前面的打字/删字压紧凑来腾时间。
- 从一个人的房间转到另一个人的房间（《unhappy》26.45–28.10，用户定的「镜头从主角的房间出来，灯光关闭，移动并放大到她的房间」）：一个连续镜头——房间内景 → 往后拉出窗户看到整栋楼 → 停一下，灯「咔哒」灭 → 甩过街（缩小一点露出街道）→ 推进对面唯一亮着的窗 → 穿过玻璃接着推向人物。窗户里画的就是那个房间（不是剪影），所以进出窗户是无缝的；窗户要和楼上其他窗在同一个格子里、同样大小（用户指出过「窗户没对齐」）；窗户做成画面比例 9:16，正好能铺满画面。整段 1 秒用户说太短，约 1.6 秒（出窗 0.55、看灯灭 0.5、甩过去加推进 0.7）。做法见 reference/unhappy-chat/act2.ts 的 nightStreet/roomWindow。
- 哭是重点时要给情感运镜：穿过窗户进来后不停，一路慢慢推到她的哭脸（越推越慢、最后还在微微动），轻微倾斜（−0.04 rad）、房间背景逐渐虚化（`filtered` blur 0→6px）、四周压暗，脸停在歌词上方；抽泣用两个频率叠的上下起伏。约 1.6 秒，落在唱 unhappy 的那句上，切到她手机时正好是下一句开头。
- 要观众读一段话（她不敢发的 50 字草稿）：手机放大到 1.34–1.44 倍，草稿框放在大字幕带和歌词之间（y≈720–1150），给约 3 秒只让人读（《unhappy》叠在这里的反转大字幕用户要求删掉，画面已经说清楚时不要再叠解说字幕）；犹豫不要让触点「晃来晃去」（三次移过去又缩回被用户否掉），用户定的是：拇指按在「发送」上一直没松手（按钮变深绿，没松手所以没发出去）→ 把 App 划回主页（窗口缩回微信图标）→ 进回忆；后面再发时从主页点开微信（窗口从图标里展开），草稿还在输入框里，前后呼应。主页壁纸可以藏线索（她的壁纸是他送的草莓牛奶）。
- 同一个画面不要超过约 1.5 秒：《unhappy》书后脸红的镜头 2.1 秒，用户说「相同画面太久了」。重做成按拍的三个镜头（约 0.5 / 1 / 1 秒），每个都给新信息、带运动：他在笑 → 课本一下举起、她从书后偷看、镜头推近 →「放学后」她偷偷拿走他留下的草莓牛奶（给前面的线索一个答案）。拿东西贴脸的手臂也要是 V：右臂默认 bend +1，要让肘部朝下传 `bendR: -1`（左臂是 `bendL: 1`）。
