# 下一支视频流程
做下一支 s0rrow 风格 MV 的步骤、每支要改的地方和检查清单，照着走。

## 开工前先定
- 时长 45–60 秒，用剪辑版歌曲（跳过重复的副歌，在同一小节起拍处衔接）；反转放 30 秒前后，兑现后 5 秒内收尾。原作品 99 秒、完播 4.16%，平均只看 15 秒。
- 反转的「为什么」要拍出来（原作品：一直开着飞行模式）；留一个能重看的彩蛋（原作品：状态栏 ✈ +「回到第 5 秒」）。
- 开头 1 秒：钩子文字首帧完整出现、主体在动。
- 每 4–5 秒一个新事件；情绪镜头用主角面部特写，不拍空镜，不用画面把歌词再演一遍。
- 这些来自发布复盘，依据和更多做法见经验库「剧情音乐短片」的 下次怎么做.md。

## 搭建
1. `materials_link` 引用 s0rrow，`materials_use` 锁定要用的文件。歌曲和歌词由用户提供。
2. 复制文件到新作品：
   - `code/*.ts` → `scenes/lib/`，其中 `grain.ts`、`lyrics.ts` → `scenes/`，`sfx-audio.ts` → 作品根目录 `audio.ts`
   - `templates/scene.ts`、`templates/visual.json` → 作品根目录；`templates/lyrics-data.template.ts` → `scenes/lib/lyrics-data.ts`
   - `tools/*.mjs` → `production/`；`fonts/*.woff2` → `public/fonts/`
3. 逐词时间：`node production/fetch-krc.mjs "s0rrow - 歌名" <音频毫秒> > scenes/lib/krc.ts`，先核对它打印的时长和音频一致（会自动跳过歌名、作词作曲行）。剪辑版要把时间整体平移到剪辑后的位置。
4. 写中文翻译（`lyrics-data.ts` 的 `CN`）：
   - 每句中文拆成和英文单词数相同的词，第 i 个中文词用第 i 个英文单词的时间点亮（对应的是节奏，不要求每个词意思对上）；词数不一致会报错。
   - 整句中文字数尽量等于英文音节数，方便跟旋律；冲突时意思、情绪准确和通顺优先，多一两个字可以。
   - 例：Today / I / realized / that / I / have / no / friends / and / I'm / so / alone → 今天 / 我 / 发现 / 了 / 我 / 没 / 有 / 朋友 / 而 / 我 / 好 / 孤单。
   - 不要凭听感猜时间、不要整句一起亮。
5. 改完画面文字运行 `node production/fetch-fonts.mjs` 重取字体子集；源码里没有的新符号加进脚本的符号表。

## 每支要改的地方
- `draw.ts` 顶部：`FONT_DIR`（`films/<作品名>/fonts/`）、`BPM`、`BEAT0`（第一拍时间）。
- `lyrics.ts` 顶部：`LYRICS_END`（歌词最晚消失时间）、`lineStyle()`（哪几句是桥段/最大的一句/末段）；`hook()` 里的钩子文案、缩成标题胶囊的时间、计数变化时间。
- `lyrics-data.ts`：中文 `CN`、红笔改写 `FIXES`。
- `visual.json` 每幕起点和时长（切在歌曲段落起拍处），幕数变了同步改 `scene.ts`。
- `audio.ts` 音效、`audio.json` 音效 clip 的 start（对照画面事件的绝对时间）。

## 画每一幕
- 每幕用 `designScene(options, t0, draw)`，`t0` = 该幕在 visual.json 的起点；`draw` 里用 `abs`（歌曲绝对时间），所有动画是 abs 的纯函数，随机用固定种子。
- 先在 `reference/` 找相近的镜头看写法（拿手机 act1/act5、被子 act2、秋千牵手 act3、聊天发送失败 act4、分耳机 act6），复用 kid/people/phone/hand/sets。
- 镜头切换在拍点上（`beatAt(k)`）；安全区：顶部 y<180 空着，歌词块中心 y≈1335，右侧按钮区不放字。
- 每幕在拍点和事件时间用 `preview_frames` 抽查，跑 `work_check`。
