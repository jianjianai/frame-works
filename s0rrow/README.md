# s0rrow

用 s0rrow 的歌做手绘涂鸦风剧情 MV 的经验和可复用素材。下一支视频从「下一支视频流程.md」开始。

## 文档
- 下一支视频流程.md：开工前要定的事、搭建步骤、每支要改的地方、检查和发布。
- 手绘涂鸦风格.md：线条、配色、光影、精细化建模（头发、眼睛、手、四肢、狗）、字体版式、角色、镜头。
- 剪辑和混音.md：混音规则（不压音乐）、闷音、剪掉重复尾奏和第二遍副歌、歌词跟着剪辑走。
- 发布后的复盘结论（时长、结构、开场、发布时间）在经验库「剧情音乐短片」，各作品的数据和复盘在作品的「复盘」里。

## 素材库 s0rrow（materials/s0rrow/）
- 角色、场景、道具、手机界面、效果和转场、歌词层、颗粒层、合成音效和字体都在素材库里，**直接导入，不拷进作品**（`@materials/s0rrow/code/…`）。函数、参数和用法不记在这里：用 `resources_search` 找、`resource_view` 看（带预览图），工作台「素材 → 资源」里也能预览。素材库自己的说明（目录、用法、字体许可）在它的 README.md。
- 节拍写在作品 project.ts 的 `tempo`，字体是完整的，音效直接 `audio_place`；新作品从素材库 `templates/` 起步。
- `reference/` 是几支片子的分镜代码（镜头写法参考，只看不拷，说明在 reference/README.md）。

## 用户偏好
- 抖音竖屏 1080×1920；中英双语歌词，英文逐词卡拉 OK，中文按词一一对应，中文 64px。
- 混音：音效响时不要压低音乐（不加 duck）。只有人声（配音、旁白）才可能压音乐，而且要用户明确要求。
- 手绘涂鸦风，参照歌曲封面；角色和道具要画得精细（见 手绘涂鸦风格.md 的精细化建模）。
- 歌词不随节拍弹跳，只有正在唱的词轻微放大。
- 画面「奇怪」多半是结构问题（姿势、拼接感、遮挡像面具）：先看全尺寸截图，重画结构，不要只调参数。
- 用户写时间常用「秒:百分秒」：「7:79」= 0:07.79，「39:07」= 0:39.07。
- 用户会自己在时间轴上定音乐起点；改音频前先读 audio.json。时长用户确认 46–60 秒（整首 73 秒「太长、拖沓」），尾奏只留一遍。
- 闷音不能太闷：低通 520Hz 被说「影响听感」，用 1500Hz 左右并交叉淡入。
- 回忆一律用「老式屏幕竖线」效果：画面颜色不变，只叠胶片相机效果（轻抖、颗粒、深灰灰尘、轻暗角）+ 中心一圈不明显、越往外越明显的随机竖线，进回忆用两拍的竖线转场，不配音效、不加镜头。做法和被否掉的方案见 手绘涂鸦风格.md「镜头」，代码是素材库 draw.ts 的 `oldFilm` / `oldScreenCut`。
- 剧情先给用户确认（一句话梗概 + 反转 + 结尾）再动手画：小狗视角版整支做完才被否。
- 素材库只放可复用的制作素材（代码、模板、工具、字体、参考）；不放歌曲、歌词数据、混音 audio.json。新画的、以后还会用到的东西放进素材库并声明成资源。
