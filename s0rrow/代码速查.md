素材库 s0rrow 里每个模块的函数和参数、音效配方和混音做法。

## draw.ts：基础库（设计坐标 1080×1920）
- 顶部要改：`FONT_DIR`、`BPM`、`BEAT0`（作品时间里的第一拍）。节拍：`beatAt(k)`、`sinceBeat(abs)`、`pulse(abs, decay)`。
- 补字（环境里不能跑 `node production/fetch-fonts.mjs` 时）：`asset_import` 下载 `https://fonts.googleapis.com/css2?family=<字体>:wght@<字重>&text=<新字的 URL 编码>` 得到一个 CSS，读出里面 fonts.gstatic.com 的地址，再 `asset_import` 存成 `public/fonts/<名字>-extra.ttf`；在 draw.ts 的 `FONT_FILES` 里加一行（同一个字体名、写上这些字的 unicode-range），字体按列表顺序 add、extra 放最后。做法见 work-afa1129b（i have no friends 重置版）的 draw.ts。漏字会退回系统字体，导出时可能是方框。
- 复制一个作品：`work_create` 新建空作品 → `version_restore` 到原作品的某次提交（和应用里的「副本」一样，内部名称和素材地址不变）。要选「发布」之前的那次提交：project.ts 里有 `publishedAt` 的版本恢复出来是已发布、只读的，工具里取消不了。
- 缓动：`easeOut`、`easeIn`、`backOut`、`win`、`env`；抖动：`hash(n)`、`jit(seed, amp)`（每秒换 8 次，`designScene` 自动 `setBoil`）。
- 形状（都带抖动）：`blob` 封闭样条、`curve`、`poly`、`oval`、`rbox`/`rrectPts`、`line`、`addBlob`（挖洞）；`rr` 不抖的圆角矩形（UI）。
- 构造：`tubePts(spine, widths)` 锥形管轮廓（四肢、尾巴、发绺）；`ik2(a, target, l1, l2, bend)` 两段关节；`lerp2`、`rotPt`。
- 上色：`paint`、`inkLine`、`hatch`；`shaded(ctx, path, fill, inside, stroke, lw)` 填色→裁剪内画明暗/纹理→描边（精细化的主要手段）。
- 文字：`F`（en/marker/cn/pen/ui）、`text`、`measure`、`writeOn`、`card` 时间卡（align 可 center）。
- 画面：`camera(ctx, cx, cy, zoom, rot, dx, dy)`（dy<0 整体上移，给歌词让位）、`shake`、`fillBg`、`vgrad`、`glow`、`flash`；`filtered(ctx, "blur(2px)", draw)` 离屏画再套 CSS 滤镜（景深、倒影、动态模糊；回忆不要用滤镜改色，见下面「回忆效果」）。
- 运镜更精致（i have no friends 重置版的 draw.ts）：`handheld(abs, amp, seed)` 返回 [dx, dy, rot] 的手持漂移（正弦叠加、不逐帧抖），传给 camera 的 rot/dx/dy，安静镜头 amp 4–5、紧张 7–8，同一画面跨镜头用同一个 seed；推拉用 `easeInOut` 代替线性 phase；背景景深 `filtered(ctx, "blur(1.5px)", (c) => 背景(c, abs), "bg")`（人物在它后面画，保持清晰）；甩镜头时把整个镜头包进 `filtered` 加 `blur(14·sin(π·w))` 动态模糊；跟拍（镜头跟着人平移）、揭示前从高处摇下来（dy 从 +260 缓动到 0）。场景精致化的做法（有光源的光、透视地面、分层视差、讲故事的道具）见该作品的 sets.ts。

## 回忆效果（以后所有回忆都用）
用户定的标准（为什么这样、试过哪些被否见 手绘涂鸦风格.md「镜头」）：画面颜色不变，只叠胶片相机效果 + 中心淡、外圈明显的随机竖线，进回忆用两拍的竖线转场。素材库的 draw.ts 里还没有，从这里拷到作品的 draw.ts 末尾（用到 draw.ts 的 `hash`、`filtered`、`glow`、`text`、`F`、`W`、`H`）。原件在 work-afa1129b 的 scenes/lib/draw.ts 和 scenes/act1.ts（`shotOldScreen`）。
- `oldFilm(ctx, abs, draw, key?, amount = 1, stamp = null)`：直接画 `draw`（不走离屏滤镜），再叠抖动、颗粒、闪烁、灰尘/毛发、竖线、暗角。`amount` 0.45 = 别人视角的闪回（更淡）；`stamp` 是右下角的橙色日期戳，可以根据需要传（如 "'26 10 05"），一般不加。里面可以再嵌 `filtered`（景深等）。
- `linesOutsideCentre(ctx, drawLines)`：把竖线画进离屏，用圆心在屏幕中心的径向渐变做 `destination-in` 遮罩（0.3W 内透明度 0.08 → 0.78W 处 1）。
- 转场 `oldScreenCut`：用在回忆开始前的两拍，p 从 0 到 1。

let filmTiles: HTMLCanvasElement[] | null = null; // 中灰噪点贴图，overlay 叠上只加颗粒不加颜色
function grainTiles() {
  if (filmTiles) return filmTiles;
  let s = 20261005;
  const rnd = () => (s = (s * 16807) % 2147483647) / 2147483647;
  filmTiles = [0, 1, 2, 3].map(() => {
    const c = document.createElement("canvas");
    c.width = c.height = 256;
    const g = c.getContext("2d")!;
    const img = g.createImageData(256, 256);
    for (let i = 0; i < 256 * 256; i++) {
      const v = 128 + (rnd() + rnd() + rnd() - 1.5) * 100;
      img.data[i * 4] = img.data[i * 4 + 1] = img.data[i * 4 + 2] = v;
      img.data[i * 4 + 3] = 255;
    }
    g.putImageData(img, 0, 0);
    return c;
  });
  return filmTiles;
}

export function linesOutsideCentre(ctx: Ctx, draw: (c: Ctx) => void, key = "lines") {
  filtered(ctx, "none", (c) => {
    draw(c);
    c.save();
    c.globalAlpha = 1;
    c.globalCompositeOperation = "destination-in";
    const g = c.createRadialGradient(W / 2, H / 2, W * 0.3, W / 2, H / 2, W * 0.78);
    g.addColorStop(0, "rgba(0,0,0,0.08)");
    g.addColorStop(1, "rgba(0,0,0,1)");
    c.fillStyle = g;
    c.fillRect(-100, -100, W + 200, H + 200);
    c.restore();
  }, key);
}

export function oldFilm(ctx: Ctx, abs: number, draw: (c: Ctx) => void, _key = "film", amount = 1, stamp: string | null = null) {
  const f = Math.floor(abs * 18);
  ctx.save(); // 画面抖动 ±1.25px
  ctx.translate((hash(f * 1.3) - 0.5) * 2.5 * amount, (hash(f * 2.1) - 0.5) * 2.5 * amount);
  draw(ctx);
  ctx.restore();
  ctx.save(); // 颗粒
  ctx.globalCompositeOperation = "overlay";
  ctx.globalAlpha = 0.34 * amount;
  ctx.translate(-((f * 97) % 256), -((f * 61) % 256));
  ctx.scale(1.5, 1.5);
  ctx.fillStyle = ctx.createPattern(grainTiles()[f % 4], "repeat")!;
  ctx.fillRect(0, 0, W + 400, H + 400);
  ctx.restore();
  ctx.save();
  const fl = (hash(f * 3.7) - 0.5) * 0.06 * amount; // 曝光闪烁（中性）
  ctx.globalAlpha = Math.abs(fl);
  ctx.fillStyle = fl > 0 ? "#fff" : "#000";
  ctx.fillRect(-60, -60, W + 120, H + 120);
  ctx.globalAlpha = 0.55 * amount; // 深灰灰尘
  ctx.fillStyle = "#1c1c1c";
  for (let i = 0; i < 8; i++) {
    if (hash(f + i * 9.7) < 0.55) continue;
    ctx.beginPath();
    ctx.arc(hash(f * 7.1 + i) * W, hash(f * 3.3 + i * 2) * H, 1.5 + hash(f + i) * 3, 0, Math.PI * 2);
    ctx.fill();
  }
  if (hash(f * 0.61) > 0.8) { // 偶尔一根毛发
    const hx = hash(f * 2.9) * W, hy = hash(f * 4.3) * H;
    ctx.strokeStyle = "rgba(20,20,20,0.6)";
    ctx.lineWidth = 1.6;
    ctx.beginPath();
    ctx.moveTo(hx, hy);
    ctx.bezierCurveTo(hx + 30, hy - 20, hx + 50, hy + 30, hx + 80, hy + 10);
    ctx.stroke();
  }
  ctx.restore();
  // 随机竖线：两条漂移的 + 每帧 1–3 条 + 约每秒一次的爆发
  const burst = hash(Math.floor(abs * 3) * 1.37) > 0.72 && (abs * 3) % 1 < 0.35;
  const lines = (hash(f * 0.37) > 0.45 ? 1 + Math.floor(hash(f * 0.91) * 3) : 0) + (burst ? 10 : 0);
  linesOutsideCentre(ctx, (c) => {
    for (let k = 0; k < 2; k++) {
      if (Math.sin(abs * (0.9 + k * 0.7) + k * 2.1) < 0.1) continue;
      c.globalAlpha = (0.3 + 0.25 * hash(f + k * 3.3)) * amount;
      c.fillStyle = k ? "#f3efe6" : "#0c0c0c";
      c.fillRect(W * (0.25 + 0.5 * hash(k * 5.3)) + Math.sin(abs * (1.3 + k)) * 160 + (hash(f * 1.1 + k) - 0.5) * 6, -60, 1.5 + k, H + 120);
    }
    for (let k = 0; k < lines; k++) {
      c.globalAlpha = (0.25 + 0.5 * hash(f * 2.3 + k)) * amount;
      c.fillStyle = hash(k * 9.1 + f) > 0.45 ? "#0c0c0c" : "#f3efe6";
      c.fillRect(hash(f * 3.1 + k * 7.3) * W, -60, 1 + hash(f + k * 1.7) * (k % 6 === 0 ? 5 : 2), H + 120);
    }
  });
  const g = ctx.createRadialGradient(W / 2, H / 2, H * 0.3, W / 2, H / 2, H * 0.8); // 轻暗角
  g.addColorStop(0, "rgba(0,0,0,0)");
  g.addColorStop(1, `rgba(0,0,0,${(0.38 * amount).toFixed(2)})`);
  ctx.save();
  ctx.fillStyle = g;
  ctx.fillRect(-60, -60, W + 120, H + 120);
  ctx.restore();
  if (stamp) { // 可选：右下角橙色日期戳
    glow(ctx, 850, 1598, 120, "rgba(255,140,40,0.22)");
    text(ctx, stamp, 850, 1600, { size: 48, font: F.ui, weight: 700, fill: "rgba(255,150,50,0.92)" });
  }
}

/** 进回忆的转场：p 0→1（两拍左右）。前半画当前画面，后半画回忆，竖线在中间最密，不配音效。 */
export function oldScreenCut(ctx: Ctx, abs: number, p: number, drawNow: (c: Ctx) => void, drawMemory: (c: Ctx) => void) {
  const dens = Math.sin(Math.PI * Math.min(1, p * 1.15));
  const f = Math.floor(abs * 24);
  ctx.save();
  ctx.translate((hash(f * 1.9) - 0.5) * 7 * dens, (hash(f * 2.7) - 0.5) * 3 * dens);
  if (p < 0.5) drawNow(ctx);
  else oldFilm(ctx, abs, drawMemory);
  ctx.restore();
  const n = Math.floor(8 + 40 * dens);
  linesOutsideCentre(ctx, (c) => {
    for (let k = 0; k < n; k++) {
      c.globalAlpha = (0.3 + 0.6 * hash(f * 2.3 + k)) * (0.35 + 0.65 * dens);
      c.fillStyle = hash(k * 9.1 + f) > 0.45 ? "#0c0c0c" : "#f3efe6";
      c.fillRect(hash(f * 3.1 + k * 7.3) * W, -60, 1 + hash(f + k * 1.7) * (k % 6 === 0 ? 7 : 2.5), H + 120);
    }
  });
  ctx.save(); // 白光闪烁
  ctx.globalAlpha = 0.3 * dens * hash(f * 5.7);
  ctx.fillStyle = "#fff";
  ctx.fillRect(-60, -60, W + 120, H + 120);
  ctx.restore();
}

- 窗户转场（reference/unhappy-chat/act2.ts 和 street.ts）：`street(...)` 画两栋楼（世界坐标 = 1 倍时的设计坐标，镜头 `translate(540,960) scale(Z) translate(-cam)`）；`roomWindow(ctx, rect, Z, m, focus, drawRoom)` 把整个房间画进 72×128 的窗户里：房间每单位 = `m·(Z/Z_IN)^0.75 / Z` 个世界单位（0.75 = 房间比窗户远，越近看到的房间越多），`Z_IN` 16.2 时窗户正好铺满画面、房间以 m 倍、focus 居中显示——这时换成直接画房间（同样的 m 和 focus），之后接着推。推进窗户的缩放用三次曲线 `-1.4w³+2.4w²`（结束时还有速度），接着的推镜用 `0.9·(1-(1-p)^2.7)+0.1·p` 接上同样的速度。窗框、窗台、窗外的彩灯和玻璃反光在 Z 接近 Z_IN 时都已出画或淡掉，交接无跳变。窗框/楼的线用不抖的 `rr` 和小抖动（放大 16 倍后抖动也会放大）。
- 画直边图形（三角形、箭头）用 `poly(ctx, pts, seed, amp, closed)` + `paint(ctx, null, 颜色, 线宽)`；`inkLine` 超过两个点是平滑曲线，会把三角形画成圆弧。

## 音效（sfx-audio.ts → audio.ts）
- 全部代码合成、固定种子；每个音效是 audio.json 的 generated 源（module "sfx"，trackId=名字），放在「音效」轨。
- 第一支：typing、send、fail、match、blow、flood、splat、pop、reply。小狗版：keys、doorOpen/doorClose/roomDoor、ball、slam、cough、squeak、rain（15 秒雨声）、heartbeat（渐慢）、click、splash、whoosh、xray、cash、rewind、pen、swipe/tap/chime、lightOff、flips、thumps。聊天版：whoosh2（镜头甩过街、推进窗户，0.7 秒变亮的噪声）、um（收到消息）、note（横幅通知）、typing2/typingLong（打字）、del（长按删除）、send2、lamp、powerOff、rustle（被子）、rewind2、heartFast（心跳加速）、bell（下课铃）、steps、shutter（拍照）、birds、boot（开机）、run、store（便利店门铃）、pay、door、milk、sparkle、stickerPop。
- 混音：音乐轨 duck 跟随「音效」轨（amount 0.72，attack 0.02，release 0.3）；**长音效（雨）放单独的轨，不要触发 duck**，否则整段音乐被压低；音效轨增益 1.4、送混响 bus（1.4s，0.22）；master 限幅 −1dB。
- 「闷音」：把歌曲在那一段切开，中间一段放到带低通的轨（《unhappy》聊天版：他蒙进被子时变闷，镜头退出他房间时淡回）。低通 520Hz 用户说太闷、影响听感 → 改成 1500Hz、q 0.5；进入时干声片段 fadeOut 0.35 和闷音片段 fadeIn 0.35 重叠（两段读同一个素材位置），不要硬切。闷音只盖住对应的镜头（在被子里的那一个镜头就闷那一段，镜头一换就淡回干声），用户说闷到镜头外「太长」。
- 缩短重复的尾奏：用频谱相似度找出两遍循环，前一遍保留前半（带最后一个唱词的尾音），在同一和弦位置的起拍前切，接到后一遍自然淡出的那段（《unhappy》：歌曲 85.905 → 94.083）。
- 跳过第二遍副歌（剪到 46–60 秒）：主歌2 结尾接尾奏最后一遍循环的起点。先按拍逐拍算 chroma 相似度（同一段音乐 ≈0.99，副歌和纯伴奏的同位置 ≈0.91，不同段落 0.6–0.85），再比较两边每拍的起音偏差把跨度精确到毫秒，切点放在人声空隙、起拍前约 10ms。副歌前常有拾音（"So I'll…"、"Love me"）跨小节线，要选两边人声都空着的位置。《unhappy》：歌曲 65.455 → 89.984（第 24 小节 → 尾奏第 36 小节，12 小节减 5ms），全片 57 秒。
