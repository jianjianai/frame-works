# 代码速查
素材库 s0rrow 里每个模块的函数和参数、音效配方和混音做法。

## draw.ts：基础库（设计坐标 1080×1920）
- 顶部要改：`FONT_DIR`、`BPM`、`BEAT0`（作品时间里的第一拍）。节拍：`beatAt(k)`、`sinceBeat(abs)`、`pulse(abs, decay)`。
- 补字（环境里不能跑 `node production/fetch-fonts.mjs` 时）：`asset_import` 下载 `https://fonts.googleapis.com/css2?family=<字体>:wght@<字重>&text=<新字的 URL 编码>` 得到一个 CSS，读出里面 fonts.gstatic.com 的地址，再 `asset_import` 存成 `public/fonts/<名字>-extra.ttf`；在 draw.ts 的 `FONT_FILES` 里加一行（同一个字体名、写上这些字的 unicode-range），字体按列表顺序 add、extra 放最后。格式见素材库 draw.ts 的 `FONT_FILES` 注释。漏字会退回系统字体，导出时可能是方框。
- 复制一个作品：`work_create` 新建空作品 → `version_restore` 到原作品的某次提交（和应用里的「副本」一样，内部名称和素材地址不变）。要选「发布」之前的那次提交：project.ts 里有 `publishedAt` 的版本恢复出来是已发布、只读的，工具里取消不了。
- 缓动：`easeOut`、`easeIn`、`backOut`、`win`、`env`；抖动：`hash(n)`、`jit(seed, amp)`（每秒换 8 次，`designScene` 自动 `setBoil`）。
- 形状（都带抖动）：`blob` 封闭样条、`curve`、`poly`、`oval`、`rbox`/`rrectPts`、`line`、`addBlob`（挖洞）；`rr` 不抖的圆角矩形（UI）。
- 构造：`tubePts(spine, widths)` 锥形管轮廓（四肢、尾巴、发绺）；`ik2(a, target, l1, l2, bend)` 两段关节；`lerp2`、`rotPt`。
- 上色：`paint`、`inkLine`、`hatch`；`shaded(ctx, path, fill, inside, stroke, lw)` 填色→裁剪内画明暗/纹理→描边（精细化的主要手段）。
- 文字：`F`（en/marker/cn/pen/ui）、`text`、`measure`、`writeOn`、`card` 时间卡（align 可 center）。
- 画面：`camera(ctx, cx, cy, zoom, rot, dx, dy)`（dy<0 整体上移，给歌词让位）、`shake`、`fillBg`、`vgrad`、`glow`、`flash`；`filtered(ctx, "blur(2px)", draw)` 离屏画再套 CSS 滤镜（景深、倒影、动态模糊；回忆不要用滤镜改色，见下面「回忆效果」）。
- 运镜：`handheld(abs, amp, seed)` 返回 [dx, dy, rot] 的手持漂移（正弦叠加、不逐帧抖），传给 camera 的 rot/dx/dy，安静镜头 amp 4–5、紧张 7–8，同一画面跨镜头用同一个 seed；推拉用 `easeInOut` 代替线性 phase；背景景深 `filtered(ctx, "blur(1.5px)", (c) => 背景(c, abs), "bg")`（人物在它后面画，保持清晰）；甩镜头时把整个镜头包进 `filtered` 加 `blur(14·sin(π·w))` 动态模糊；跟拍（镜头跟着人平移）、揭示前从高处摇下来（dy 从 +260 缓动到 0）。镜头往下甩（从脸甩到俯拍的桌面）用 `smearV(ctx, draw, px, key)` 竖直动态模糊；任意方向用 `smear(ctx, draw, dx, dy, key, n)`（长度 = 画面速度 px/s ÷ 48），冲镜/推进转场用 `zoomBlur(ctx, draw, cx, cy, amount, key)`（amount 0.1–0.25）——两者都在场景根变换下调用、镜头放在 draw 里。叠在镜头外、按屏幕设计像素画的东西（红笔字、固定线宽）用 `rootScale()`（mirrors 的 story.ts `px`/`toDesign`）。以上 2026-10-09 进了素材库。

## 光影（draw.ts「light and shadow」，重置版加的）
原则见 手绘涂鸦风格.md「光影」「全片光影的做法清单」，例子见 reference/no-friends-remake/。
- 离屏：`buffer(ctx, key)` 一张清空的整幅画布（同样的变换），`blit(ctx, buf, op, alpha, filter)` 合回去；`filtered` 多了合成方式 `op`。每个 key 是一张整幅画布：用完就丢的缓冲共用 key（人物边光 "rimFig"、光柱 "shaft"、窗格光 "panes"、压暗 "shade"），不要给每个人单开。
- 人物身上的光：`figureMask(ctx, draw, key)` 人物遮罩 → `onFigure(ctx, mask, paint, op, alpha, cut?)` 只照在人物上（"screen" 暖光、"source-over" 压暗，`cut` 扣掉挡在前面的桌子）；`rimLight(ctx, mask, ux, uy, width, color, alpha, op, ink, cut?, reach?)` 墨线内侧的轮廓光，`reach=[x,y,r]` 离光源越远越淡；`rimFigure(ctx, draw, ux, uy, color, alpha, width)` = 画人物 + 身后窗户/门的轮廓光（阳光 "rgb(255,238,200)" 0.5 宽 5；门里暖光 "rgb(255,222,165)" 0.55 宽 6）。
- 影子：`castShadow(ctx, light, k, draw, color, soft, alpha, clip?, figure?)` 点光源把人物放大投到墙上（叠在灯光之后，`figure` 扣掉人物本身）；`groundShadow(ctx, draw, foot, height, tip, alpha, soft, sx)` 地上的影子：脚不动，头顶落在 `tip`（路灯在身后时朝镜头拉长，经过时横到一边）。
- 空气里的光：`lightShaft(ctx, quad, x0, y0, x1, y1, rgb, a0, soft, key)` 柔边光柱；`motes(ctx, abs, x, y, rx, ry, n, seed, rgb, alpha)` 光里的浮尘；`bokehDisc(ctx, x, y, r, rgb, a)` 虚化光斑；`bloom(ctx, amount, radius, threshold)` 高光溢出，在一幕 createScene 末尾调一次（**放在镜头 if/else 链之后**，插在链中间会让后一个镜头盖住转场）；`flicker(abs, seed)` 烛光闪烁系数；`devScale(ctx)` 设计单位→像素（跟镜头走的模糊和位移用）。
- 画面：`grade(ctx, sat, draw)` 去饱和（他的灰色世界，暖色的东西在它外面画）；`blinkEyes(abs, seed, base)` 自然眨眼。
- sets.ts 里的光：`paneLight(ctx, quad, rgb, a, soft)` 地上的窗格光，`shadeAround(ctx, rgb, a, holes)` 光源以外压暗，`roomBokeh`/`streetBokeh` 光斑（画在 grade 外面、用低饱和的颜色，灰色光斑像灰尘球），`screenSpill(ctx, cx, cy, s, a)` 屏幕照在周围的光，`fairyGlow` 串灯光晕。

## 回忆效果（以后所有回忆都用）
用户定的标准（为什么这样、试过哪些被否见 手绘涂鸦风格.md「镜头」）：画面颜色不变，只叠胶片相机效果 + 中心淡、外圈明显的随机竖线，进回忆用两拍的竖线转场。都在素材库 draw.ts 里（用法见 reference/no-friends-remake/act1.ts 的 `shotOldScreen`）。
- `oldFilm(ctx, abs, draw, key?, amount = 1)`：直接画 `draw`（不走离屏滤镜），再叠抖动、颗粒、闪烁、灰尘/毛发、竖线、暗角。`amount` 0.45 = 别人视角的闪回（更淡）。里面可以再嵌 `filtered`（景深等）。
- `linesOutsideCentre(ctx, drawLines)`：把竖线画进离屏，用圆心在屏幕中心的径向渐变做 `destination-in` 遮罩（0.3W 内透明度 0.08 → 0.78W 处 1）。
- 转场 `oldScreenCut(ctx, abs, p, drawNow, drawMemory, at = 0.5)`：用在回忆开始前的两拍，p 从 0 到 1；在 `at` 前后从现在溶成回忆（回忆自动走 oldFilm），竖线在中间最密。最好做成匹配剪辑：两边同一张脸、同样大小和位置（重置版：黑屏里的倒影 → 上午的他）。

## 音效（sfx-audio.ts → audio.ts）
- 《mirrors》加了：paperSlap（滑过+啡地糊上，啡在 0.89 s）/tape/scribble（红笔）/ring（视频来电）/hangup/slider/zero/dive/ticks/alarm/peel/metalDoor/slip（墨镜滑下）/freeze/flip/sheet（扔床单，落地闷响在 0.5 s）/whip（甩镜、冲镜）/rip/doubleTap，和 `swish` 小函数。
- 重置版加了：bellElectric（电铃上课铃）、horn（派对喇叭）、floodFast（七条通知间隔 0.12 秒）。
- 全部代码合成、固定种子；每个音效是 audio.json 的 generated 源（module "sfx"，trackId=名字），放在「音效」轨。
- 第一支：typing、send、fail、match、blow、flood、splat、pop、reply。小狗版：keys、doorOpen/doorClose/roomDoor、ball、slam、cough、squeak、rain（15 秒雨声）、heartbeat（渐慢）、click、splash、whoosh、xray、cash、rewind、pen、swipe/tap/chime、lightOff、flips、thumps。聊天版：whoosh2（镜头甩过街、推进窗户，0.7 秒变亮的噪声）、um（收到消息）、note（横幅通知）、typing2/typingLong（打字）、del（长按删除）、send2、lamp、powerOff、rustle（被子）、rewind2、heartFast（心跳加速）、bell（下课铃）、steps、shutter（拍照）、birds、boot（开机）、run、store（便利店门铃）、pay、door、milk、sparkle、stickerPop。
- 混音：**音乐轨不加 duck，音效响的时候不压低音乐**（用户在《mirrors》里发现音效一响音乐就变小：「这个应该只有人声才这样，并且除非明确要求这样，都不要这样做」）。只有配音/旁白这类人声才考虑压低音乐，而且要用户明确要求。音效靠自己的增益定位（音效轨 1.3–1.4，个别提到 2.4），送混响 bus（1.4s，0.2）；master 限幅 −1dB 兵底（《mirrors》去掉 duck 后全片峰值 −1dB、无削波）。前几支用过的「音乐 duck 跟随音效轨」不要再用。
- 「闷音」：把歌曲在那一段切开，中间一段放到带低通的轨（《unhappy》聊天版：他蒙进被子时变闷，镜头退出他房间时淡回）。低通 520Hz 用户说太闷、影响听感 → 改成 1500Hz、q 0.5；进入时干声片段 fadeOut 0.35 和闷音片段 fadeIn 0.35 重叠（两段读同一个素材位置），不要硬切。闷音只盖住对应的镜头（在被子里的那一个镜头就闷那一段，镜头一换就淡回干声），用户说闷到镜头外「太长」。
- 缩短重复的尾奏：用频谱相似度找出两遍循环，前一遍保留前半（带最后一个唱词的尾音），在同一和弦位置的起拍前切，接到后一遍自然淡出的那段（《unhappy》：歌曲 85.905 → 94.083）。
- 跳过第二遍副歌（剪到 46–60 秒）：主歌2 结尾接尾奏最后一遍循环的起点。先按拍逐拍算 chroma 相似度（同一段音乐 ≈0.99，副歌和纯伴奏的同位置 ≈0.91，不同段落 0.6–0.85），再比较两边每拍的起音偏差把跨度精确到毫秒，切点放在人声空隙、起拍前约 10ms。副歌前常有拾音（"So I'll…"、"Love me"）跨小节线，要选两边人声都空着的位置。《unhappy》：歌曲 65.455 → 89.984（第 24 小节 → 尾奏第 36 小节，12 小节减 5ms），全片 57 秒。
