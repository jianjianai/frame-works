# 柔和扁平2D骨骼动画

用代码做「柔和扁平插画 + 二维骨骼 / 剪纸人物」动画的经验：画面风格和配色、人物结构与站姿、骨骼和零件的画法、动作的物理和走位、光影、让画面稳定不闪的做法。来自《引力》（草稿 3d80f743，成品 b80f18ef）。每种情绪用什么运镜见经验库「情绪运镜」；剧情、分镜节奏、切点转场和发布复盘见经验库「剧情音乐短片」。

## 用户偏好
- **画面不压抑**：灰黑剪影、重暗角、黑夜被否两次；配色按音乐的感觉设计，符合国内大众审美（见 `画面风格.md`）。
- **人物结构照参考设定图量**：用户给了《罗小黑战记 2》的正面设定图，关节高度、胳膊长度按它定，不凭感觉、不按「几个头长」算（第一版胳膊长了 40%，用户：「手臂的长度和身体比例不对」）。
- **直立但放松**：先被说「弯腰驼背」，矫枉过正改成脖子长、方肩、直筒、立正，又被说「人物比例太僵硬，头、脖子、肩膀和外套没有形成协调的整体」。要的是自然、协调、轻盈、可爱，不是军姿、不是服装模特。改比例时整体一起调，「不要一次又一次地只改驼背」。
- **四肢只在关节处弯**：胳膊腿是两段直的，不要一整条弯的香肠形。
- **人物要好看，不只是比例对**：几何体拼出来的人偶被说「太丑了」；先设计剪影和部件造型，标志物（大靴子）可以夸张（见 `骨骼与画法.md` 的「先定轮廓」）。
- **画面不能闪**：人物边缘一直闪烁被一眼看出来（原因是阴影的画法，见 `光影与稳定.md`）。
- **呼吸要看得出来**：试过把呼吸减到只抬一点肩，用户要求改回来（吸气时胸口、脖子、头跟着上来一点，肩再多抬一点）。
- **动作讲物理惯性**：不要跟着拍子一下一下硬拉（见 `动作与走位.md`）。
- **真侧面不做**：主要角色做正面、3/4 侧，背面骨架自动就有，不单独打磨；片子里用不着的面不花时间（用户：「人物背面这个视频中貌似也用不着」）。正侧面只临时画出来检查重心。

## 文档
- `画面风格.md`：「柔和扁平」的配色和画面做法（粉橙淡紫的天、糖果色的城、夜是靛蓝、回忆是褪色老照片、轻暗角）、一直在飘的灰和雪、全景里的小人。
- `人物结构与站姿.md`：按身高比例定关节、头颈肩、外套和围巾的剪影、放松的站姿，以及两次被否的样子。
- `骨骼与画法.md`：三维关节投影成二维零件的骨骼、转面、反向运动学、直的四肢、椭圆的头和贴在球面上的五官、头发和衣摆的惯性。
- `动作与走位.md`：动作的物理（跃起、落地、重量、惯性下坠到停）、交接东西、二维画面里的前后和走位、一串人吊着、人链、一拍一步长大、倒着的人。
- `光影与稳定.md`：卡通阴影和受光边怎么画才不闪、呼吸和眨眼、怎么检查闪烁。
