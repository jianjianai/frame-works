# 情绪运镜
把每段情绪对应到镜头的表达技巧：哪种情绪用什么运镜（推、拉、跟、甩、定住）、什么速度曲线、幅度、倾斜和抖动，光、暗角、提示框和音效怎么跟着走。来自《屏蔽》（用户：「做的太完美了，把我惊艳到了」）、《unhappy》、《mirrors》和《引力》草稿（用户：「完美，草稿定稿！」），作品 id 见经验库「剧情音乐短片」的 `作品.md`。切点、转场、节奏和分镜的通用做法在「剧情音乐短片」；人物和画面怎么画在各风格的经验库（「柔和扁平2D骨骼动画」「s0rrow」）。

## 用户偏好
- **先说情绪，再做镜头**：用户会一段一段说出情绪（第一幕「兴奋 → 疑惑 → 紧张 → 被监视」，第二幕「心酸 → 想念 → 孤独 → 犹豫 → 沉思 → 期待 → 失望」），没说到的段落要「按照之前的方案」自己补齐（第三幕就是这样补的，用户最满意）。做分镜表时就把每段的情绪和它卡的歌词列出来请用户确认。
- **运镜是草稿的灵魂**（《引力》：「重点是运镜，运镜是草稿的灵魂，也是整个视频的灵魂」）：草稿画面可以简单，镜头的路线、速度曲线、落点和情绪要一次做到位。
- **镜头语言要贯穿全片**（《屏蔽》：「全部的画面都完美了，但是镜头语言从31秒后面都需要优化一下，你按照之前的方案优化一遍看看」——后半段几乎每镜都是不动的手机或慢推）。
- **人物的速度就是镜头的速度**：老人慢（「老人操作手机没有这么快」）；突然的念头只比平常快一点（0.7 秒；0.3 秒「太快了」，1.4 秒又只像平静）。
- **要读的屏幕镜头要稳**：读屏时不晃、不歪、不后拉、不加暗角。
- **关键的一下不切特写，用情绪运镜推过去**（《引力》掏砖递砖：「这里不要硬切镜头，而是采用情绪运镜方法」）。
- **情绪用人物在主线里做的事来表现**，不插空镜和道具，不用文字把情感高潮说出来（`被否的做法.md`）。
- **不动已经满意的运镜**：画面满意时只改镜头；精细化建模时不改已通过的运镜。运镜按每段情绪单独设计，不给全片套一套统一的「顺滑」缓动或停—动—停节奏（两轮这样的重做被要求全部退回草稿）。

## 通用做法
1. 每段一种情绪，切换点卡在歌词上（乐句结尾、下一句第一个字）。情绪运镜叠在推进剧情的事件上：动起来但没有新信息的情绪镜头照样掉人（哪种留人、哪种掉人的数据见「剧情音乐短片」的 `剧情推进.md`）。
2. 按 `情绪与镜头对照.md` 选：镜头怎么动、速度曲线、幅度、倾斜和抖动；光和暗角；黄色提示框和音效跟同一个节奏。
3. 速度曲线本身就是情绪：
   - 线性慢逼近 = 紧张、警觉。
   - 越推越快（pow 2.2–2.4）= 期待、被吸进去。
   - 越推越慢（easeOut）= 后悔、心碎、余韵。
   - 回弹（backOut 0.16–0.24 秒）= 兴奋、意外、发出去了。
   - 不到 0.2 秒的猛推 + 抖 = 被监视、惊恐、震惊。
   - 一顿（停住 + 1% 的小冲）= 下决定、按下去的那一下。
   - 直直落到目标 = 决绝；凑过去又退回 = 犹豫。
   - 漂着后退 = 怀念；几乎不动 + 慢慢压暗 = 心酸、愣住。
4. 光跟情绪：暖 = 爱和希望，冷、降饱和 = 孤独和失去；暗角收紧 = 压力、羞耻、出神，松开 = 释然。
5. 情绪要接：下一镜开头还带着上一镜结尾的情绪（偏远、偏暗、眉头难过），再进入这一镜的情绪；镜头数值怎么接见「剧情音乐短片」的 `切点与转场.md`。
6. 代码写法见 `实现配方.md`。检查：整段均匀取样看情绪曲线，preview_frames 一次只调一个（并行会串画面）。
