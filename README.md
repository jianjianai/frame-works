# s0rrow

用 s0rrow 的歌做手绘涂鸦风剧情 MV 的经验和可复用素材。下一支视频从「下一支视频流程.md」开始。

## 文档
- 下一支视频流程.md：开工前要定的事、搭建步骤（含怎么从素材库取出文件）、每支要改的地方、检查和发布。
- 代码速查.md：素材库 s0rrow 每个模块的函数和参数、音效和混音。
- 手绘涂鸦风格.md：线条、配色、精细化建模（头发、眼睛、手、四肢、狗）、字体版式、角色。
- 发布后的复盘数据和结论（时长、结构、开场、发布时间）在经验库「剧情音乐短片」。

## 素材库 s0rrow（materials/s0rrow/）
- `code/`：draw（手绘引擎+tubePts/ik2/shaded/filtered）、kid（主角+女主 who:"girl"，精细版）、people（路人/朋友/兽医，精细版）、dog（小狗豆豆）、chat（微信风格聊天/朋友圈/资料卡/关机）、phone、screens（相册/存钱/接单）、hand、sets（第一支场景）、places（玄关/卧室/女生房间/教室/走廊/清晨街道便利店/雨夜/公交站/宠物医院/封面的树）、shared、grain、lyrics、sfx-audio（三套合成音效）。
- `templates/`：scene.ts、visual.json（55 秒四幕）、歌词数据模板。
- `tools/`：fetch-krc.mjs（酷狗逐词时间）、fetch-fonts.mjs（字体子集）。
- `fonts/`：六个手绘风字体（按原作品用字子集化，换文案要重新取）。
- `reference/`：《i have no friends》六幕和封面；`reference/unhappy/`：《unhappy》小狗版四幕；`reference/unhappy-chat/`：《unhappy》聊天版五幕 + story.ts + timeline.ts。只看不拷。

## 用户偏好
- 抖音竖屏 1080×1920；中英双语歌词，英文逐词卡拉 OK，中文按词一一对应，中文 64px。
- 手绘涂鸦风，参照歌曲封面；角色和道具要画得精细（见 手绘涂鸦风格.md 的精细化建模）。
- 歌词不随节拍弹跳，只有正在唱的词轻微放大。
- 画面「奇怪」多半是结构问题（姿势、拼接感、遮挡像面具）：先看全尺寸截图，重画结构，不要只调参数。
- 用户写时间常用「秒:百分秒」：「7:79」= 0:07.79，「39:07」= 0:39.07。
- 用户会自己在时间轴上定音乐起点；改音频前先读 audio.json。时长用户确认 46–60 秒（整首 73 秒「太长、拖沓」），尾奏只留一遍。
- 闷音不能太闷：低通 520Hz 被说「影响听感」，用 1500Hz 左右并交叉淡入。
- 回忆一律用「老式屏幕竖线」效果：画面颜色不变，只叠胶片相机效果（轻抖、颗粒、深灰灰尘、轻暗角；日期戳可以根据需要加，一般不加）+ 中心一圈不明显、越往外越明显的随机竖线，进回忆用两拍的竖线转场，不配音效、不加镜头。做法和被否掉的方案见 手绘涂鸦风格.md「镜头」，代码见 代码速查.md「回忆效果」。
- 剧情先给用户确认（一句话梗概 + 反转 + 结尾）再动手画：小狗视角版整支做完才被否。
- 素材库只放可复用的制作素材（代码、模板、工具、字体、参考）；不放歌曲、歌词数据、混音 audio.json。
