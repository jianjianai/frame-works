# AI生视频现实题材温情短片

「AI生视频现实题材温情短片」类作品的制作经验。关联了这个经验库的作品，AI 开始制作时会先看这里。

## 文档
- `开头钩子.md`：开头 2~5 秒情绪最强且必须是主线，不用无关路人戏；每个镜头都要推进剧情或带动情绪。
- `Seedance提示词写法.md`：用户偏好的少约束写法（通用背景 + @ 行 + 时长 + 镜头N：事情和台词）；要写什么、不写什么；试拍发现的容易被理解错的写法；@ 参考怎么排。
- `场景参考图.md`：给视频模型当参考的空场景图：精简提示词怎么写，怎么检查（机位、道具时间、暗场打光、防恐怖片化）。
- `时代背景提示词.md`：给视频模型交代年代和社会环境：两三句并进通用背景，闪回自带背景，年龄核对，审核时怎么改。
- `视频提示词的台词与声音.md`：视频模型同时生成声音时，台词怎么写才对得上（说话人和 @音频、字数、画外音、戴口罩和画外音最容易说成乱码），音效交给模型，声音怎么统一。
