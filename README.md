# s0rrow
用 s0rrow 的歌做手绘涂鸦风剧情 MV：画面风格、角色画法、手机界面，和素材库 s0rrow 的用法。下一支视频从「下一支视频流程.md」开始。制作顺序、剧情、分镜节奏、切点转场、剪辑混音和发布复盘在经验库「剧情音乐短片」；每种情绪用什么运镜在「情绪运镜」。

## 用户偏好
- 手绘涂鸦风，参照歌曲封面；角色和道具要画得精细（`角色画法.md`）。光影和美感也是留存的关键，特别是开头（`手绘涂鸦风格.md`）。
- 抖音竖屏 1080×1920；中英双语歌词，英文逐词卡拉 OK，中文按词一一对应，中文 64px；歌词不随节拍弹跳，只有正在唱的词轻微放大。
- 画面「奇怪」多半是结构问题（姿势、拼接感、遮挡像面具）：先看全尺寸截图，重画结构，不要只调参数。
- 手太难画就不画：手机近景只画手机和白色触点（「手太难做就不做了，只显示手机」）；必须露手时用简单的圆手。画不好的小部件藏到物体后面、用动作交代（`手机界面.md`）。
- 回忆一律用「老式屏幕竖线」效果：画面颜色不变，只叠胶片相机效果（轻抖、颗粒、深灰灰尘、轻暗角）+ 中心一圈不明显、越往外越明显的随机竖线，进回忆用两拍的竖线转场，不配音效、不加镜头（`手绘涂鸦风格.md`「回忆」）。
- 素材库只放可复用的制作素材（代码、模板、工具、字体、参考）；不放歌曲、歌词数据、混音 audio.json。新画的、以后还会用到的东西放进素材库并声明成资源。

## 素材库 s0rrow（materials/s0rrow/）
- 角色、场景、道具、手机界面、效果和转场、歌词层、颗粒层、合成音效和字体都在素材库里，**直接导入，不拷进作品**（`@materials/s0rrow/code/…`）。函数、参数和用法不记在这里：用 `resources_search` 找、`resource_view` 看（带预览图），工作台「素材 → 资源」里也能预览。素材库自己的说明（目录、用法、字体许可）在它的 README.md。
- 节拍写在作品 project.ts 的 `tempo`，字体是完整的，音效直接 `audio_place`；新作品从素材库 `templates/` 起步。
- `reference/` 是几支片子的分镜代码（镜头写法参考，只看不拷，说明在 reference/README.md）。
