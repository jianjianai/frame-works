# 骨架剪纸动画

深色描边、平涂上色的 2D 角色，头、头发、衣服、四肢、鞋像剪纸一样分成部件绑在骨架上，靠骨骼转动做动画——这类作品的制作经验。关联了这个经验库的作品，AI 开始制作时会先看这里。

- `角色骨架.md`：用代码搭剪纸角色——正面 ↔ 3/4 转面、合并描边和阴影、围巾和手臂的前后、FK/IK、走跳跪的做法和踩过的坑。
- `配角线稿.md`：**照参考图做配角**——骨架用主角的，脸、头发、衣服从参考图拿轮廓（用户在底稿 SVG 里画，或工具按颜色描），换算进素材库；工具清单、每一步的命令、描图和换算踩过的坑。
- `配角头发.md`：**配角的头发要分层**——为什么（描一块剪影的反思）、流程（用户分块画、或我用工具照参考图描点 → 认块起 id → 两张按标志点逐块对应、节点原样保留）、谁压谁（后面那片合并描边、压在脸上的只描皮肤上和伸出去的边、远处鬓发藏到脸后面、马尾跟着身子换层、发髻、秃顶的白发在耳朵后面）、刘海上沿要在脸的圆顶外面、朝右时头整个镜像（用户定的）；路人用的通用发型。
- `头发.md`：主角长发——头顶 + 几缕的结构、垂着 / 风 / 失重同一套算法、大风时耳朵旁的接缝和吹散、失重时用户定下的样子（改了好几轮，再动先问）、鬓发的远侧遮挡和近侧竖直。
- `动作.md`：动作和表情——关键帧写关节角度、按着地点踩地、钉脚不打滑、走和跑、头发跟着速度甩、眉毛被刘海挡住时怎么做表情。
- `服装.md`：在做好的基础模型上穿衣服——和用户共编服装线稿、外套盖住身子和手臂的前后、卷袖子、袖标、硬靴子；配角从主角外套的前襟改出几种版型（西装、夹克、开衫……）、细节按画面大小省略。
- `进场景.md`：定稿的角色放进片子以后——光效不能把人物染色、描边按镜头远近保持粗细（不然用户会以为模型被改了）、场景特效的细节，以及几十个人同场怎么撑住预览。
- `接入片子.md`：已经做好动画的片子换上骨架角色（写转换层，不重排动作）；风要接上、手臂按弹簧跟随、叠连续的小动作，不然又死又僵；转身过正面会整套镜像。
- `站位与够得着.md`：排动作前先量够不够得着、侧面看不出朝镜头的动作、手伸到一点用数值 IK、人在场景里站得住和纵深。
- `互动动作.md`：《引力》里两个人和道具的动作——拽下来、坐地、递东西、抱人、伏案写字、人走进门里、拴着的细线和重物（绳子和摆的模拟）、脱下来的靴子、躺下时头发的重力、家具按身长做、钻被子、松着慢慢拉直的绳子、往上冲被拽住；做不出的手部动作（一根根掰手指）换个表现，不硬做。
