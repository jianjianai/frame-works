# s0rrow

用 s0rrow 的歌做手绘涂鸦风剧情 MV 的经验和可复用素材。下一支视频从「下一支视频流程.md」开始。

## 文档
- 下一支视频流程.md：开工前要定的事、搭建步骤、每支要改的地方、检查和发布。
- 代码速查.md：素材库 s0rrow 每个文件、各模块的函数和参数、音效和混音。
- 手绘涂鸦风格.md：线条、配色、字体版式、角色和手的画法。
- 发布后的复盘数据和结论（时长、结构、开场、发布时间）在经验库「剧情音乐短片」。

## 素材库 s0rrow（materials/s0rrow/）
- `code/`：手绘引擎、主角、路人、手机、手、场景、颗粒、歌词图层、合成音效。
- `templates/`：scene.ts、visual.json（55 秒四幕）、歌词数据模板。
- `tools/`：fetch-krc.mjs（酷狗逐词时间，已验证）、fetch-fonts.mjs（字体子集）。
- `fonts/`：六个手绘风字体（按原作品用字子集化，换文案要重新取）。
- `reference/`：原作品《i have no friends》的六幕镜头代码和封面，只看不拷。

## 用户偏好
- 抖音竖屏 1080×1920；中英双语歌词，英文逐词卡拉 OK，中文按词一一对应，中文 64px。
- 手绘涂鸦风，参照歌曲封面。
- 歌词不随节拍弹跳，只有正在唱的词轻微放大。
- 画面「奇怪」多半是结构问题（姿势、拼接感、遮挡像面具）：先看全尺寸截图，重画结构，不要只调参数。
- 用户写时间常用「秒:百分秒」：「7:79」= 0:07.79，「39:07」= 0:39.07。
- 素材库只放可复用的制作素材（代码、模板、工具、字体、参考）；不放歌曲、歌词数据、混音 audio.json。
