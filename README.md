# 骨架剪纸动画

深色描边、平涂上色的 2D 角色，头、头发、衣服、四肢、鞋像剪纸一样分成部件绑在骨架上，靠骨骼转动做动画——这类作品的制作经验。关联了这个经验库的作品，AI 开始制作时会先看这里。

- `角色骨架.md`：用代码搭剪纸角色——正面 ↔ 3/4 转面、合并描边和阴影、围巾和手臂的前后、FK/IK、走跳跪的做法和踩过的坑。
- `头发.md`：长发和鬓发——头顶 + 几缕的结构、垂着 / 风 / 失重同一套算法、大风时耳朵旁的接缝和吹散、失重时用户定下的样子（改了好几轮，再动先问）、鬓发的远侧遮挡和近侧竖直。
- `动作.md`：动作和表情——关键帧写关节角度、按着地点踩地、钉脚不打滑、走和跑、头发跟着速度甩、眉毛被刘海挡住时怎么做表情。
- `服装.md`：在做好的基础模型上穿衣服——和用户共编服装线稿、外套盖住身子和手臂的前后、卷袖子、袖标、硬靴子。
- `进场景.md`：定稿的角色放进片子以后——光效不能把人物染色、描边按镜头远近保持粗细（不然用户会以为模型被改了）；风要接上、手臂按弹簧跟随、叠连续的小动作，不然又死又僵；转身过正面会整套镜像；排动作前先量够不够得着、侧面看不出朝镜头的动作、手伸到一点用数值 IK、几十个人同场怎么撑住预览。
