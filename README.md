# 情绪运镜
剧情短片里「先定每段情绪，再用镜头、光和切点把情绪拍出来」的做法。来自《屏蔽》（frame-works/73c8f9bc）用户逐段定下的全片运镜（用户：「做的太完美了，把我惊艳到了」），以及《unhappy》（work-d1187f37）、《mirrors》（work-9586fbc4）的经验。

## 用户偏好
- **先说情绪，再做镜头**：用户会一段一段说出情绪（第一幕「兴奋 → 疑惑 → 紧张 → 被监视」，第二幕「心酸 → 想念 → 孤独 → 犹豫 → 沉思 → 期待 → 失望」），没说到的段落要「按照之前的方案」自己补齐（第三幕就是这样补的，用户最满意）。做分镜表时就把每段的情绪和它卡的歌词列出来请用户确认。
- **切点不能硬**：上一镜的终点就是下一镜的起点。用户点名过的硬切：手机后面的背景换了一张图、往后拉又马上切回特写再切桌面、哭脸直接切到手机。没有动作带的切点，加一个看得见的人物动作（拿起手机、放下手机、看过去）把镜头带过去。
- **在一个镜头里用运镜做变化，不靠多切**：每镜至少 1–1.5 秒；4 秒三个硬切「太硬」，0.5–1 秒一个镜头「来不及看完」，一个画面不动 3 秒「无聊」。
- **人物的速度就是镜头的速度**：老人慢（「老人操作手机没有这么快」）；突然的念头只比平常快一点（0.7 秒，0.3 秒「太快了」）。
- **要读的屏幕镜头要稳**；一次只做一个动作，动作在切镜前做完。
- **不动已经满意的东西**：画面满意时只改镜头；精细化建模时不改已通过的运镜。不要给全片套一套统一的「顺滑」缓动或停—动—停节奏（两轮这样的重做被要求全部退回草稿）。
- **多发挥，比用户的判断更好就提出来并优化**（「你做后面部分的时候，判断比我的更加准确……」「以后你要自己多发挥，只要是比我判断的更好的就可以提出来，进行优化」）。不用等用户点名：做任何修改时顺手看哪里的镜头、衔接、可读性、情绪能更好，直接提出并改好，告诉用户改了哪几处、为什么。被要求「全片优化」时逐镜复查：用户逐段定过、点名满意的保留，只改镜头死了、字看不清、情绪或切点接不上的地方，并告诉用户改了哪几处、为什么。

## 通用做法
1. 每段一种情绪，切换点卡在歌词上（乐句结尾、下一句第一个字）。情绪运镜要叠在推进剧情的镜头上：动起来但没有新信息的情绪镜头照样掉人。
2. 按「情绪与镜头对照」选：镜头怎么动（推、拉、跟、甩、定住）、速度曲线、幅度、倾斜和抖动；光和暗角（暖 = 爱和希望，冷、降饱和 = 孤独和失去；暗角收紧 = 压力、羞耻、出神，松开 = 释然）；黄色提示框和音效跟同一个节奏。
3. 速度曲线本身就是情绪：
   - 线性慢逼近 = 紧张、警觉。
   - 越推越快（pow 2.2–2.4）= 期待、被吸进去。
   - 越推越慢（easeOut）= 后悔、心碎、余韵。
   - 回弹（backOut 0.16–0.24 秒）= 兴奋、意外、发出去了。
   - 不到 0.2 秒的猛推 + 抖 = 被监视、惊恐、震惊。
   - 一顿（停住 + 1% 的小冲）= 下决定、按下去的那一下。
   - 漂着后退 = 怀念；几乎不动 + 慢慢压暗 = 心酸、愣住。
4. 每镜把镜头（手机在画面上的位置、人脸的缩放、亮度、暗角、光色）写成时间的函数，下一镜从上一镜在切点的值出发；表情和速度也接上（上一镜停住，下一镜柔和起步）。
5. 检查：每个切点渲染前后各一帧对比；整段均匀取样看节奏。preview_frames 一次只调一个，并行会串画面。
