# 逐字歌词
让歌词逐字对上人声的做法：从酷狗拿官方逐字时间（KRC），不靠猜，也不用起音检测。

## 用户偏好
- 歌词要逐字卡准人声。《可是妈妈》（a603fe8d）先用起音检测去猜时间，用户反馈还是对不上，所以直接用酷狗官方的逐字时间。
- **整句一起出来，卡拉 OK 高亮，不要一个字一个字地出来**（《引力》697a72af，用户：「不要一个字一个字的出来，改成每次一句，正在被唱的字高亮，没被唱的字和被唱过的字用不同的显示方式」）：没唱的字淡、正在唱的字换亮色（加光、放大一点）、唱过的字实。手写的字（砖上的「活下去」）可以唱到时像笔写出来一样扫亮。
- **歌词跟着画面换位置、换排列**（同一次：「画面变化的时候，歌词为了构图实时可以移动位置，或者改变排列，不用固定」）：切镜、推拉以后原来的空处被人占了，整句挪到新的空处，可以横排变竖排、拆成两行；路上会压到人时原地淡出、在新位置淡入。和前后句放在同一个地方时一先一后，不叠在一起。
- 歌词的构图和动效要和画面互动、带情绪（《引力》的做法：飘、沉、光、红绳、刀、裂，见作品 AGENTS.md「逐字歌词」）。

## 文档
- `酷狗逐字歌词.md`：怎么从酷狗拿到每个字的时间（KRC 的搜索、下载、解密），怎么解析和核对。
- `人声分离核对.md`：KRC 也会错（快板挤成每字 0.06 秒、拆开唱的合成一句、整句早晚），用人声分离逐字核对、修正。
